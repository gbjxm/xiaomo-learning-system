# 学习小岛：统一应用中的学习部分

正式入口：[学习小岛](http://127.0.0.1:8787/learning/)。来源是小陌指定的「规划Agent时代个人系统 (2)」聊天和 `web/设计提案/结构层-v1/主岛结构草图.html`；历史源稿保持原样，正式副本位于 `web/public/learning`。

## 现在怎样使用

2026-10-05 已接入[我的内容](http://127.0.0.1:8787/learning/content/)：四岛个人创作、想法和观看入口通向同一处，默认展示全部最近内容，可切换“创作与想法／观看记录”。从故事、影像或后期岛进入只保留来处提示，同一份内容可以跨岛继续。看片入口可预选观看记录。课程、学习向导、安排、休息与领航生活旅程保持原职责；本轮验收见[交付记录](../三系统工作台/四岛内容整合交付记录.md)。

从个人主岛选择全天、下午＋晚上或一段时间。起止、课长、材料和去向可改，先看当前一步，后续可编辑、取消、恢复。**手动安排按填写值生成**，不把它说成模型已经理解了自然语言或已完成学习。

切到「和向导聊聊」，选择交流用途，再发送当次问题。它实际请求现有学习后台；失败保留原话、输入和请求标识，成功回复的保存结果分别显示。可勾选「只聊不记」。真实安排或自然收尾按原学习保存规则写入项目Markdown；模型连接沿用现有配置，本轮没有改模型/账号/代理或新增付费接口。

2026-10-03 起，课程架读取正式课程记录；可以选课程、留下可选课次并粘贴文字或转写，按当前问题读取对应正式课文。路线、反馈和接续引用同一任务与观察点，保存冲突可读取最新记录后保留输入继续。实际实现、CLI、验收与真实文字样板见 [学习核心交付](深层优化交付.md)。图片、声音和视频仍需实际专业分析，不由网页文字向导假装审看。

在四岛之间探索、记录当前活动。新的个人内容和轻练习由“我的内容”收纳；原有书签、练习草稿仍可从“旧学习书签”或共享页的“回到原处继续”找回。离开原学习页前先核对UI状态保存；刷新、重新打开或服务重启时恢复。首次UI文件由明确初始化请求建立，后续GET仅读取，缺失/损坏/身份错误不显示假恢复。初次空状态不冒称已有书签。

## 保存各自负责什么

| 内容 | 权威位置及含义 |
|---|---|
| 原界面草稿、手动时间方案、当前位置、旧自有练习草稿、手动书签、近期交流显示 | `学习小岛/data/ui-state.json`；只帮助接续界面，不认证能力或自动写成学习进展 |
| 新个人创作、想法与附在同条内容里的练习 | `运行记录/我的内容/*.json`；与学习任务分开，保留补充和更正版本 |
| 观看记录 | `运行记录/观影记录.md`；唯一观看台账，只留片名也可以，不要求感想、评分或看完 |
| 真实学习安排、报告、困惑、个人复盘与下一步 | `运行记录/`及既有学习后台；按项目运行约定、明确请求和自然收尾保存 |

共享页只读引用旧 UI 与领航原内容，原件不迁移。观看日期未提供就保留未知；后续集数、感受或再次观看接续同一 W 编号。网页与 Codex 使用 `node web/content/cli.mjs` 的 `bootstrap`、`list`、`detail`、`save --input <JSON文件>` 共用同一内容保存层，具体提交及回读约定见[运行约定](../运行约定.md#个人内容与观看登记)。保存一条内容不会自动生成学习任务或能力进展；来源链接也不代表系统审看过媒体。正式作品工程仍由原影视工作流管理。

UI保存有数据身份、版本冲突、相同提交去重、原子写入和实际回读。另一页面更新时阻止旧版本覆盖；保留本页草稿，可下载，再读取最新版本并共同合并。保存失败不提示成功，浏览器本地草稿仅作回退，磁盘结果仍须确认。

UI状态上限128KiB，保持必要接续，不归档无限聊天全文。提示超限时下载草稿再整理；不要删除真实记录去通过限制。原课程架、练习、窗口提示等仍按实际能力显示：自有练习不是原课程；提醒仍是手动试听/提示，没有后台计时或打卡。丰富景观并非所有细节都已经成为小陌的最终取舍。

## 模块协作与备份

顶部同页切换 `/learning/`、`/observatory/`、`/information/`。素材研究仍在用户明确请求后的Codex中进行，不因为逛岛或收藏自动研究；信息库只有手动检查更新才采集。

统一启动、停止、完整数据备份与本次证据见[三系统整合](../三系统整合.md)。UI文件包含个人原话与近期交流，按私人资料保管；不上传额外第三方。不用模型额度也可恢复已有界面和浏览已存资料，真实问答仍取决于现有连接。
