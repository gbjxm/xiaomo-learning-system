# 四系统接入个人终端：本轮交付

2026-10-04。小陌已确认主岛通用交流接同一领航助手，并授权先把既有功能与已定设置放进 A 版终端。本轮已接入并启用 [正式个人终端](http://127.0.0.1:8787/)。用法与资料位置见 [接入说明](个人终端接入说明.md)。

## 已接入

- A 版四岛与领航船成为默认首页；已批准的岛屿、小猫与海景资产进入正式静态目录。
- 主岛及领域岛的地点进入原学习功能；实际学习场景也共用同一套图像。原课程、时间入口、学习向导、练习、看片、学习书签和休息保留。
- 主岛随手交流和船内领航桌进入同一个领航页；同标签页返回保留最近聊天与未发送草稿。旅程原话、AI 理解和学习记录继续分开。
- 主岛个人旅行手记与船内旅程册进入同一份旅程；原学习书签仍有独立入口。
- 船内素材、信息入口接回完整原模块；统一导航支持回主岛、回船、直接换模块和原资料查找。
- 进入学习先等待原记录与 UI 恢复；明确选择新课程时不重绑旧任务，课程接口失败时不把原课程编号保存成空值。
- 离开前完成学习草稿与工作台阅读位置的原受控保存；从船返回素材时找回原详情及筛选。

没有搬迁数据库、领航目录、知识树或创作工作流，没有新增第二套个人背景、课表或学习任务存储。本轮未实施后续深层协作。

## 已知限制与接续

1. **信息详情的精确滚动位置有偏移。** 本轮同一1280宽度的测试中，从详情回船再进入信息台，同一内容和笔记恢复，但滚动从520变为35；另一次为2527变为2042。没有再次保存笔记。该项没有报通过，留待日常网页使用优化；未采用无效的额外布局等待。
2. 领航最近聊天是按资料身份和标签页隔离的浏览器会话；需正式留下时仍使用原明确保存方式。它没有成为跨浏览器、跨设备的聊天数据库。
3. 原资料查找继续覆盖学习UI对象、素材与信息，未扩大成包含全部正式学习和领航记录的全局检索。
4. 原三模块日常备份脚本未扩为四系统统一恢复；本轮领航另有逐文件保护。手机、云端、语音与后台提醒未实施。

本轮代码修改前已保全于 `protection/project/`，原领航资料于 `protection/navigation/`；另有三模块数据包 `备份/三系统-20261004-155916-17d23e70.zip`。数据包SHA-256为 `bfc38c08ea2b3bb96880bd75b5684608507a1e7b5604013e1b7dfbdad6affb6c`。

`publish-manifest.json` 列明启用文件及前后哈希；`code-diff.patch` 保存可读差异。`restore-code.py` 默认只检查并报告，不改文件；实际恢复须明确传 `--apply`，且当前文件必须仍匹配本轮启用哈希，防止盖掉其他工作。它只恢复原代码与入口，不改业务数据、不删除新资产；数据恢复仍走各模块原受控方式。

隔离 `8797/8798` 测试服务已停止。正式服务继续使用原启动/停止脚本，设计预览 `8796` 保留。
