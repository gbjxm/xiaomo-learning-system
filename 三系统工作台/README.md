# 个人空间的跨区引用与阅读接续

本目录保存三个区域之间的可选引用和阅读位置。学习、素材、机会与作品仍以各原模块为权威数据；引用不复制正文，也不自动开始研究、安排学习或确认资格。

日常入口为 `http://127.0.0.1:8787/explore/`。模块日常布局带 `?space=daily`；原来的根地址及三个模块地址继续保留。启用与验收状态见本目录交付说明。

`data/workspace-state.json` 是独立状态文件，包含双方可见的单一引用、最近打开的对象和筛选、滚动、折叠位置。阅读接续与真实学习进展分开。原学习 UI 仍在 `学习小岛/data/ui-state.json`，真实记录仍在 `运行记录/`。

日常页面使用本机令牌、来源身份、版本与提交标识写入，并回读核对。跨区关系只有直接引用，不作传递推断；解除仅移除引用。对象移除后保留不可用提示，撤销解除也不会复活原对象。另一页面已更新时先重新读取核对；提交结果未知时保留原标识重试。

受控 CLI 为 `node web/workspace/cli.mjs help`。读取不创建文件，初始化仅能创建不存在的新文件。不要手改 JSON、覆盖已有身份或把测试文件接为正式数据。隔离运行须使用本轮指定验证目录与 `scope=isolated`。

统一数据备份在存在此文件时一并保存；旧备份没有包含的引用无法补出。恢复先到新隔离目录，不自动切换正式资料。源码和实施前保护备份保留于 `验证/三系统整合/日常体验优化-20261002-450bc2/`。
