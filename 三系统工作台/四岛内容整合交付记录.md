# 四岛共享“我的内容”交付

2026-10-05。依据小陌采用的方案，四岛保留名称与视觉，个人创作、想法、练习和观看入口汇入同一处[我的内容](http://127.0.0.1:8787/learning/content/)。默认显示全部，按需切换“创作与想法／观看记录”；直接点击某岛的看片入口时预选观看。

## 实际改变

- 四岛的写作、分镜、节奏与内容展架通向同一批内容；从另一岛进入不重新创建。主岛第三个重复的学习快捷位改为“我的内容”，原当前一步和页头继续学习保留。
- 可以只留一句想法，也可以只记一个片名。补充、更正和再看仍接续原编号，旧版本可查。未知观看日期、进度不自动改成当日或已看完。
- 故事便签、分镜顺序和节奏示意继续可用，保存到同一条创作中。工坊切换和重新打开保留原练习设置，自由正文不会被练习摘要替换。示意工具不等于真实视频编辑或媒体生成。
- 原看片台账、旧界面草稿／书签、正式学习任务及文字产物、领航原灵感保留来源。原处内容在共享页只读呈现，仍可回原入口继续；来源错误有提示，不伪装成没有记录。
- 课程、学习向导、安排、休息以及主岛生活旅程保留原分工。普通网页学习聊天没有升级为自动观影片单登记；正式登记使用共享内容页或同一 CLI。

## 数据与协作

新的创作和练习保存在 `运行记录/我的内容/content_*.json`，包括当前内容、历史版本与提交回执；观看继续使用原 `运行记录/观影记录.md`，保留旧 W 表并追加本次原话与结构化记录。没有另建一套观看事实库，也没有把长期内容塞进界面草稿。

网页与 Codex 共用 `node web/content/cli.mjs bootstrap|list|detail|save`；实际输入和写后回读见 [连接层说明](../web/content/README.md)。日常规则已补入 [运行约定](../运行约定.md#个人内容与观看登记)。单纯留下想法或观看经历不自动创建学习任务、能力进展或正式影视项目。

浏览器草稿按资料、条目和标签页分别保存。未知保存结果保留原请求并锁定输入，先重试核对；版本冲突读取最新内容供对照，再由用户手动保存。单文件原子写入、共享学习锁、原请求幂等与回读保护并用，不能把普通手动文件编辑视为受控事务。

原观影台账以及新增内容位置都在既有备份脚本递归覆盖的 `运行记录/` 中；原外部领航备份范围保持此前说明。恢复必须核对正式与隔离身份，本轮没有移动正式数据目录。

## 验证结果

**49/49 项相关 Node 检查通过。** 覆盖内容存储、HTTP／CLI 与真实宿主集成、四岛入口保存保护，以及既有学习和领航宿主回归；包括读取零写、仅片名、原话与原表保留、连续更正、同编号再看、并发锁、版本冲突、跨进程重复提交、来源不可用、损坏数据、路径与访问保护。

Edge 隔离浏览器实际走通：

- 原标题／正文空白保留；跨岛继续同一条；追加、更正及旧版本回读。
- 只填片名、同一作品补集数、再次观看保留未知日期和状态。
- 工坊单独保存、工坊内保存、跨岛恢复与切换工具；原正文和故事草稿不丢，节奏游标在现有安全策略下可运行。
- 故意丢弃已经写入的响应、模拟保存后的 HTTP 500，刷新后仍保留原请求；重试没有重复记录。另一次保存抢先完成时，本页保留原话并对照后继续。
- 四岛相关热点、主岛共享快捷入口、旧学习入口转接、旧草稿精确回原工坊，以及服务重启后已存内容回读。
- 默认列表、折叠查找、等高卡片、长原文独立滚动；桌面与 390 像素宽度无横向溢出；未保存草稿跨岛恢复，两个标签页互不覆盖。

所有业务写入检查仅在隔离副本进行，未调用真实模型。故障检查产生的网络失败、500 和 409 是主动注入；正常页面检查没有脚本或样式加载错误。上述结果不证明学习收益、作品效果或实际看听过媒体。
