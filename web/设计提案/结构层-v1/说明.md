创建日期：2026-09-24；最近调整：2026-09-29。小陌已采用四岛总体结构，并在体验路径加入后提出“不够丰富”，授权结合优质游戏、项目与个人使用场景继续发挥。当前草图把四岛景观、可探索的物件和低成本小练习接入原有学习路径，并接入主岛的“三种时间入口＋当前一步＋可调整的后续安排”。它仍是独立交互演示，不是正式学习终端或最终皮肤；完成代码不表示新增体验已经被小陌采用。

## 当前入口与建议点击路径

用 Microsoft Edge 打开同目录的[主岛结构草图](主岛结构草图.html)。请保留整个 `结构层-v1` 文件夹：HTML 依赖同目录四组 CSS/JS——[体验流程](体验流程.js)、[岛屿场景](岛屿场景.js)、[学习工坊](学习工坊.js)、[海岛生活](海岛生活.js)，以及新增的[时间安排核心](时间安排核心.js)、[主岛安排交互](主岛安排.js)和[主岛安排样式](主岛安排.css)。可以直接本地打开，无需启动正式学习服务。

当前有两条入口：想看看这一版的趣味性，可以先自由探索；想核对时间安排怎样帮助学习，再走下面的完整路径。两条路共享本页状态，不要求先完成安排才能逛岛。

### 先自由探索这一版

1. 在主岛点击房屋、课程架、放映场、练习桌、手记架或长椅；点击小猫可以摸摸它、一起去海边坐坐。小伙伴没有饥饿、打卡或连续登录要求。
2. 去影像岛点 **“分镜练习台”**，把门口、信封、人物三张原创静帧换个顺序，写一句叙事意图；改动后可点 **“把这份草稿留在岛上”**。初始示例不能直接记成自己的练习。
3. 去故事岛点 **“写一小段”**，修改人物的想要、阻力或变化；去声音港湾点 **“节奏练习台”**，改变静帧顺序与停留时长，观看游标节奏示意。声音选项只记录意图，不播放配音、音效或生成视频。
4. 在各岛的放映角选择 **“只想欣赏”** 或 **“带一个观察点”**，继续用自己的播放器看片。片名与一句感想都可留空，不强制拉片；有想留的话时再夹进书签。
5. 点长椅，选 **“让小岛安静陪一会儿”**，收起工作窗口；休息好了可回到当前活动。顶部可切清晨、午后、晚风气氛，手动打开低音量海声或关掉动效。这是气氛预览，不是正式皮肤切换。
6. 点岛上的痕迹架或主岛手记，打开刚才保留的草稿并接着改。书签只在本页内存，刷新会清空；不会因为点击或停留就自动长出成就。

四岛分别采用家园、故事花园、采光工坊、声音港湾的二维景观，每岛有六个主要地点与一只可点击的猫。物件为原创 SVG，地图里的书签数量来自本页实际留下的条目。

### 主岛的三种时间入口

- **全天有空**：先给上午、下午各留一段，晚上为可选窗口。默认起止只是建议，可以按当天实际情况改动；已过去的窗口不补排。
- **下午＋晚上**：下午开始，晚饭后接同一份材料。晚间可以取消，已做过的内容与停止处保留。
- **一段时间**：默认三小时，可选四小时或修改起止。准备、休息和收尾都在窗口内，不把所有空闲时间当作连续学习时间。

生成安排后，当前行动卡显示在输入框前，优先说明这一块做什么、怎样收尾；材料与理由收在折叠区。展开“稍后怎么安排”可修改后续内容和时段，也可取消某段。编辑生成候选预览，明确点“应用这次调整”才采用；“保留原安排”可撤回候选。课长未知时，当前一步先确认真实课程位置和时长。

已有活动时，调整入口锁定当前材料和归属，只调整时间与做法，避免重排时替换正在学习的内容。其他岛仍可自由浏览；收尾后再安排新内容。调整保留交流、未完成的收尾输入、停止处和练习草稿；切换到另一活动时，课长按该活动的已知信息恢复，未知则保持未知。快捷调整不消费未发送的聊天文本。

### 再检查一次完整学习路径

第一次建议用默认示例看完整流程：

1. 在主岛点 **“用一段示例走一遍”**，查看从 **14:30 开始的“下午＋晚上”** 安排，课程时长明确假设为 **60 分钟**。它不是你的真实课表或课程时长。
2. 看“这次，先做这一块”的收尾点，按需要展开材料与理由，点 **“从这一步开始”**，进入影像与 AI 创作岛。
3. 在岛内切换 **学习桌、课程架、留下的痕迹**：桌面承接当前活动，课程架提供材料位置，痕迹处暂时为空。
4. 点 **“去学这一块”**，查看切去外部课程或创作软件时的状态；可以收起右侧面板，也可以直接回来聊一个问题。
5. 展开 **“学习与休息的轻提醒”**，点 **“预览一次提醒”**。提示只在本页出现，可选“歇一会儿”“稍后再说”或“这次不提醒”；勾选后会尝试播放一次轻声。这里没有真实倒计时。
6. 休息后点 **“休息好了，继续”**；在“直接聊聊”里输入简短体会，查看交流怎样接在同一活动上。向导回应只是说明流程的模板，不会讲解真实课程。
7. 点 **“这块先到这里”**，可留下收获、疑惑或下次位置，再点 **“留下本页书签”**。也能选择“这次不留，先结束”，不要求每节课总结。
8. 点开书签看内容，再试顶部 **“模拟下次打开”**：回到主岛后可找回本页的活动或书签。它演示接续路径，不测试真正关闭后的恢复。

另可检查：活动开始后点“只剩半小时”，课长容纳不下时整课顺延，只保留可完成的小步，后续窗口先不安排；课长未知时先核对，不凭空判定能否看完。查看调整预览后点“应用这次调整”才采用，当前活动与草稿保持。也能从“先逛逛”进入任一岛，或在主岛直接聊天，不必先走完整安排。

## 当前做到什么，尚未做到什么

- 四岛地图与右侧浮动交流面板保留，岛内近景增加了不同地形、房屋、路径、课程架、放映角、练习台、长椅、痕迹架和小猫。物件打开对应的内容窗口，窗口可关回场景；影像岛以“老白的分镜课”为已知在学线索，真实课次、课程链接和进度仍未知。其他两岛没有虚构课程或老师。
- 三种时间入口、当前行动卡和折叠的后续安排已可操作。安排由选项、填写的时间与课长和模板规则生成，不理解自然语言中的时间或自动判断目的岛；“安排一下”和“直接聊聊”是两种交互入口，均未接 API 或模型，不产生模型接口费用。
- 可以手动切换外部学习、休息、返回和收尾状态，不监控其他软件，也不将页面停留时间视为学习完成。普通浏览其他岛不会自动切换当前活动。
- 提醒只由按钮手动预览，可选择播放真实的短提示音；没有启用学习或休息计时，也没有后台任务、系统通知或跨软件提醒。声音能否稳定在后台播放尚待工程实测。
- 对话、安排、活动和书签全部保存在本页内存。**刷新或关闭会清空；“模拟下次打开”复用现有内存，不是持久化。**没有写入个人情况、当前状态或正式学习历史。
- 三类原创小练习可以实际编辑并保留本页版本，支持从书签重新打开；示例素材不来自老白课程，也不代表课程作业。这里没有自动专业点评、评分或掌握认证。剪辑练习的计时游标仅演示画面停留，不是学习或休息倒计时。
- 海声需主动打开，使用浏览器合成的环境声；清晨、午后、晚风为当前页面的色调变化，动效可关闭并尊重系统减少动态偏好。没有安装第三方音效项目、加载其素材或实现正式换肤。
- 书签区分暂停、观看自述和“做过练习但未查看产物”，不会自动形成掌握结论。收尾表单用于体验状态与保存位置；正式自然交流保存仍须接入后端，不将这个表单固化为每课必填流程。
- 录音、上传与转写、真实课程播放、正式保存、保存失败处理和完整服务退出均未接入本草图。周/月入口只说明方向安排的关系，未编造真实计划。
- 景观、建筑和动物已经形成可操作的候选表达，最终美术、正式皮肤和镜头参数仍待使用反馈确定。本轮流程交互完成不表示使用体验已经被小陌采用，也不证明实际学习收益。
