# 本轮实施说明

只修改当前a-selected目录，除主执行者更新外层比较页与建设入口外，不改v2的原A/B/C及正式web/public。

1. 布局继承已采用A版：主岛左中最大，story右上，visual右中，post右下，新船左下近海。沿用1440×900与1280×800的位置尺寸，修正图像替换带来的必要标签干涉，不重排布局。
2. 主执行者提供home.png/story.png/visual.png/post.png新图及对应SVG封装。封装沿用900×650坐标和原scene-place标签、点击热点；原素材位于references。不得将四张图仅用于缩略图却让展开回到旧矢量图，首页和展开视图应使用同一新版图。
3. 图像内部不依赖生成文字。界面文字与点击入口独立保留。主岛的当前一步、随手交流、继续学习与原地点仍有前端响应；其他岛沿用已有功能边界。图像生成的位置有漂移时，结合实际新图调整热点/标签，不能明显指向空地。
4. 船舱窗外使用assets/ocean.svg（另一执行者提供）替换旧故事岛窗口。窗口继续保留圆形舷窗与船舱布局，海景有清晰但轻柔的天空/海面/地平线，不能包含岛、陆地、建筑；保持装饰aria-hidden/inert。
5. 将“方向A尚未选定”“三方向比较”等文案更新为“A版·视觉优化预览”，保留说明本页不保存/不连接正式服务的必要提示。输出index.html，可兼容保留a-harbor.html同内容，外层8796首页将引向本目录。
6. 新船已由用户认可沿用，本轮不重画。所有正式模型与保存接口仍不连接，不制造用户活动、课程进度、自动回复或保存成功。

更新主要由a-build.py构建，独立封装生成脚本由主执行者维护。收到四岛资产就绪消息后再最终build。主执行者负责统一Edge截图、主岛及船窗核对、代表性点击及返回验证。
