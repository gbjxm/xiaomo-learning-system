# 电脑探索预览

第一阶段独立预览入口：<http://127.0.0.1:8790/preview/>。正式入口仍为 <http://127.0.0.1:8787/>，没有切换默认页。

总览是三处可点击、可用键盘进入的岛岸；学习区域沿用原四岛、课程与练习，素材保留完整正文与来源，信息保留宽详情和规则。统一顶栏可以切换区域或返回自由探索。工作栏可收起；信息详情内也能直接返回总览。区域内的当前位置、筛选和滚动保留在本预览标签页，跨模块业务关联尚未实现，也没有假成功按钮。

2026-10-02 视觉打磨：三处岛岸分别使用草木、采光与暖沙色，增加原生 SVG 的屋顶、窗光、木料和岸边层次。课程架、练习桌、看片角、收藏架、研究台、机会公告和准备桌均有真实入口；悬停或键盘聚焦时，顶部地点说明会显示用途，收藏和机会数量来自现有只读接口。点击才进入原功能。研究台只浏览已存专题，准备桌打开原作品与准备页。普通说明文字提高了对比度；系统减少动态效果时预览跟随关闭。

同日内部页面打磨：素材收藏以已登记本地图、原件类型、已有概要和研究状态组织列表；视频定位图与示意图明确标注，未填写的个人感受保持空缺。完整解读采用连续正文和桌面侧边阅读目录，专业记录、依据与来源可按需展开。信息收集以简介、奖励口径、资格和时间组织条目，辅助筛选与作品条件合并展开；原有未知、限制、历史与更新失败仍明确显示。机会详情保留完整规则、证据和个人草稿，预览保存动作给出未提交反馈。

## 启动与停止

先保持原8787服务正常运行，再在PowerShell运行：

```powershell
& 'D:\codex\小陌的学习系统\web\preview\Start-Preview.ps1'
```

打开上述8790网址。此脚本只启动独立预览，不启动或停止原业务服务。启动时会核对原8787项目身份；端口被占用或原服务不符时拒绝启动。已在运行时直接打开网址即可。

预览启动窗口按Ctrl+C，或运行：

```powershell
& 'D:\codex\小陌的学习系统\web\preview\Stop-Preview.ps1'
```

停止脚本只停止身份相符的8790预览，不停止8787或信息后台。

## 使用范围

- 可浏览正式资料、展开原文/来源、调整筛选及预览布局。
- 学习输入、手动方案和界面操作只留在本预览标签页的sessionStorage；不写正式UI文件或学习记录。关闭标签页后不保证继续保留。
- 预览不发送模型请求，不执行收藏、笔记保存、采集、备份、恢复或投稿。其他模块的保存接口统一返回明确的预览拒绝，正式使用通过右上角入口进入。
- 正式8787页面、原模块代码与业务数据库结构均保留。三模块在同一预览页面框架里运行，没有iframe。
- 当前只核验电脑端1280×800、1440×1000、1920×1080；手机布局不在本阶段范围。

## 实现与回退

全部实现位于本目录：`server.mjs`为固定本机只读代理与独立静态入口，`adapt.mjs`只转换预览响应中的学习持久化逻辑，`public/`提供探索图景、导航壳、样式和返回适配。响应采用同源CSP；保存方法在代理前拒绝。适配源码标记变化时拒绝转换，避免静默漏掉新的写入路径。

停止预览即可回到原使用方式。无需回写数据库、迁移原记录或恢复旧首页。代码/数据保护与实际操作证据见项目 `验证/电脑探索预览-20261002/`。
