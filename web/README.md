这是学习系统的本地网页入口。首页从现有 Markdown 文件读取阶段方向、最近记录和接续点；你可以说明今天的时间与意图，之后自主看课、看片或创作，遇到问题再回来交流。正式学习状态仍由项目根目录的 `运行记录/` 保存；浏览器只在当前标签页暂存聊天显示。

## 启动

学习终端原有功能需要 Node.js 20.6 或更新版本。素材观察室使用 `node:sqlite`，要求 Node.js 24.15 或更新版本；本轮实际验证版本为 **24.15.0**。观察室按路由加载，运行版本不满足要求或模块加载失败时会单独提示，不提高原学习功能的兼容要求。本项目没有 npm 依赖。在 PowerShell 中运行：

```powershell
& 'D:\codex\小陌的学习系统\web\Start-LearningTerminal.ps1'
```

浏览器打开 [学习终端](http://127.0.0.1:8787)。服务只监听本机地址，按 `Ctrl+C` 停止。初次打开网页只读取状态；点击发送后才请求模型。

也可在另一窗口运行以下停止脚本；它会核对本机端口的进程确为本项目 `server.mjs`，不会停止无关服务：

```powershell
& 'D:\codex\小陌的学习系统\web\Stop-LearningTerminal.ps1'
```

再次运行 `Start-LearningTerminal.ps1`，再打开原地址即可继续。自定义 `LEARNING_PORT` 时，浏览器使用对应端口，停止脚本传入 `-Port <端口>`。

## 素材观察室

同一服务中的正式入口是 [素材观察室](http://127.0.0.1:8787/observatory/)，也可从学习终端导航进入。链接、文字或文件有一种即可收藏；标题、标签与「为什么吸引我」可以后补，无需先建研究专题。收藏不会请求模型或自动读取外部链接。

需要深入时，在素材详情建立或关联专题，点击「交给 Codex 继续研究」，复制交接文本并粘贴到 Codex，明确本次问题。Codex 依据保存的 ID、版本和阶段记录，通过受控 CLI 读取与回写；网页点击「重新加载」可查看最新结果。原素材、初始感受、修正历史、备注与研究正文分别保存。剪贴板不可用时可手动全选复制或下载交接文本。

数据位置、成果导出与完整备份见 [素材观察室使用说明](../素材观察室/README.md)；研究行为与新聊天接续见 [研究入口](../素材观察室/研究入口.md)，共同接口见 [共同读写规则](../素材观察室/共同读写规则.md)。观察室与学习记录使用各自的数据位置，不将收藏或测试写成学习进展。

[信息收集](http://127.0.0.1:8787/information/) 已通过固定本机代理接入统一应用，不用iframe、不放宽原Host/Origin/令牌/CSP。正常启动自动启动或复用身份相符的原Python服务；停止只回收自身启动的子进程，既有独立信息服务不误停。原8765直接入口仍兼容，数据没有迁移。

## 聊天连接

默认尝试复用这台电脑已经登录的**原生 Codex CLI**。这条路径由本地服务执行一次只读、临时的 Codex 对话，网页本身不接收登录凭据；聊天接续由网页服务提供。默认使用该登录支持的模型；`LEARNING_CODEX_MODEL` 可单独指定，不沿用兼容接口的 `LEARNING_API_MODEL`。它不等于找到了 Codex 当前使用的兼容 API 地址。首页会显示实际使用的是“Codex 本地登录”还是“兼容接口”。

以后若拿到了兼容接口地址，把 [.env.example](.env.example) 复制成 `web/.env.local`，填写 `LEARNING_API_BASE_URL`、`LEARNING_API_MODEL` 和专用的 `LEARNING_API_KEY`，重启服务。Base URL 例如以 `/v1` 结尾，本地服务会请求其 `/chat/completions`。设置了有效接口地址和专用密钥时优先使用该接口；未设置地址时继续使用原生 Codex。`.env.local` 已被 [.gitignore](.gitignore) 排除，密钥只由本地服务读取，不能填在网页聊天框里。

如果两种连接都不可用，页面仍可读取学习状态，但不会假装聊天成功。当前本机 Codex 登录与默认模型已通过一次不保存的真实请求；将来登录或模型状态变化时，以当次发送结果为准。

## 学习记录

- 明确请求的安排保存为**待执行计划**；课程看完、概念理解和实际作品表现分开记录。
- 主动报告进展或自然收尾时，记录你的原话摘录与当次回应要点；没有报告的进展保持未知。
- 勾选“这次只聊，不保存”可跳过本轮写入。只有文件保存成功，网页才显示“已写入学习记录”；保存失败会明确提示。
- 网页按需读取本项目运行约定、状态与有关技能文本作为对话依据。原有知识库检索、影视工作流操作及 Codex 的工具能力尚未直接接入网页；需要分析具体素材时可粘贴内容，或继续在 Codex 中处理。
- 2026-09-30 补齐：对话会读取 [课程记录](../运行记录/课程记录.md) 与 [观影记录](../运行记录/观影记录.md)，并给现有个人资料保留更完整的上下文；文件更新后，下次请求重读。当前仍不从网页交流自动逐项更新课程/片单，两份台账由 Codex 总协调维护；超过单文件上下文预算时会明确节选。完整功能与欠缺项见 [功能设定清单](../功能设定与缺口清单_v1.md)。

兼容接口采用 [Chat Completions 消息格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，第三方实现的细节以实际接口为准。原生 Codex 路径使用 [非交互模式](https://learn.chatgpt.com/docs/non-interactive-mode)；本地服务调用时限制为只读并禁用会话持久化。
