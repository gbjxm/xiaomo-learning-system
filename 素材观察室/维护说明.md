# 素材观察室：维护说明

更新：2026-10-01。第一版 schema 2，实际运行 Node 24.15.0、Python 3.12.10、FFmpeg/FFprobe 8.1.2；未安装新依赖。正常网页和 CLI 使用固定正式目录，不需常驻第二个观察室服务。

## 备份与恢复

网页底部的「数据位置与备份」可以建立和下载完整 ZIP；CLI `backup` 同样调用一致性快照及附件打包模块。建立后返回包 ID、路径、字节数、哈希与内容清单。备份失败保留原库，不报告成功；正在上传的 `.incoming` 临时文件不纳入，因此重要上传应先完成再备份。

备份包含素材、原话修正历史、备注、所有专题及阶段、来源与版本、提交收据、登记原件和已完整落盘但登记不确定的原件。还包含数据身份、结构与运行要求。应用源码另由本轮保护备份保全；其他系统、凭据、旧备份不进入素材 ZIP。

恢复流程拒绝现有目录、正式目录、危险 ZIP 路径和哈希不符。先恢复到全新隔离目录，再检查，不自动切换正式入口。示例（把包路径替换为实际返回值；目标名每次用新的）：

```powershell
$observatoryCli = 'D:\codex\小陌的学习系统\web\observatory\cli.mjs'
node $observatoryCli restore --package 'D:\codex\小陌的学习系统\素材观察室\backups\实际备份文件.zip' --target 'D:\codex\小陌的学习系统\验证\素材观察室\阶段5\恢复检查-新的名称\data'
node $observatoryCli identity --data-dir 'D:\codex\小陌的学习系统\验证\素材观察室\阶段5\恢复检查-新的名称\data'
node $observatoryCli list-materials --status all --data-dir 'D:\codex\小陌的学习系统\验证\素材观察室\阶段5\恢复检查-新的名称\data'
node $observatoryCli list-topics --data-dir 'D:\codex\小陌的学习系统\验证\素材观察室\阶段5\恢复检查-新的名称\data'
```

恢复保留 storeId 和记录 ID，重绑实际路径并标为 isolated；不可仅因 storeId 相同就向它当正式库写入。核对所有附件 SHA-256、历史成果和关联后，若确需将恢复内容替换正式库，作为一次明确的恢复任务执行，先保护当前正式数据并停止服务。第一版没有自动覆盖正式库的命令，不用文件管理器直接覆盖运行中的库。

本次含真实隔离研究数据的恢复实际完成：5 条素材、2 个专题、3 个阶段、2 个原件逐字段与哈希核验通过。正式空库的备份也另行恢复通过；详见验收记录。第一版 ZIP 上限为总内容 4 GiB、10,000 文件，超限明确失败；未做超大库压力测试。

## 写入失败时

- 版本冲突：保留输入，重读新记录及素材版本，合并后使用新 submissionId；网页保留草稿。
- 忙、锁等待、结果不确定：同提交 ID、同内容重试，检查持久化收据，不另外创建一次。
- 同 ID 不同内容：明确拒绝，不能当重试。
- 上传中断或格式失败：清理临时文件；已有原件和业务记录保留。
- 完整原件落盘后登记失败：原件保留；用原上传 ID 和同文件重试登记。完成原件也纳入完整备份。
- 写入成功而后续页面加载失败：按返回记录 ID 重新加载，不重新创建。服务重启后页面令牌更新，重新打开页面；草稿确认后重试。

详细 JSON 合同、错误和 HTTP 请求见共同读写规则。日常只用受控 CLI，不自由执行 SQL 修复用户记录。

## 运行与安全限制

学习终端保持原有本机 Host/Origin 限制；观察室写接口另核对页面令牌。页面 CSP、正文安全渲染、HTTP(S) 链接校验、上传白名单、真实路径/junction 边界及包校验已检查。外部材料只作资料，不执行其中指令；媒体工具输入协议仅允许本机 file/pipe。

观察室按路由加载。缺库、错误范围、SQLite 或运行版本不满足时给出模块错误，保留旧学习终端入口。实际版本仅验证上述环境，没有擅自扩大兼容矩阵；更换 Node 或媒体工具后应重新运行相关隔离验收。

同一机器上的本地程序仍可能访问本机服务，actor 字段也不是账号认证。第一版没有账号、远程部署、云同步或私人附件外传。成果导出/备份会包含原话和附件，按私人资料保管。
