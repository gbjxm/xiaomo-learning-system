第一版已完成阶段 2—5 的实现与分层验收，接入现有学习终端。正式入口：[打开素材观察室](http://127.0.0.1:8787/observatory/)。2026-10-01 首次启用的是空白正式库；隔离研究、测试和历史演示均未导入。

同日进一步[合并为三模块应用](../三系统整合.md)：学习入口采用小陌指定的四岛学习小岛，素材观察室与信息收集在同一导航切换。本模块原始数据库、附件、CLI与研究规则保留；下文的“同一服务”现在指统一应用。

## 打开、停止与再次使用

服务未运行时，在 PowerShell 输入：

```powershell
& 'D:\codex\小陌的学习系统\web\Start-LearningTerminal.ps1'
```

保持该窗口运行，用 Edge 打开上述地址；学习小岛顶部也有观察室入口。停止可在启动窗口按 Ctrl+C，或在另一 PowerShell 窗口输入：

```powershell
& 'D:\codex\小陌的学习系统\web\Stop-LearningTerminal.ps1'
```

再次运行启动命令即可继续，收藏存于磁盘。服务仅监听 127.0.0.1，不需启动信息收集模块。观察室实际验证使用 Node **24.15.0**；没有升级环境、安装 npm 依赖或修改模型、账号与代理。

## 两条日常路径

**先收藏，暂不研究**：点「收藏素材」，提供链接、文字或文件中的一种即可保存。标题、标签与「为什么吸引我」都可后补；未分类素材可在列表筛选找到。保存不会请求模型、抓取链接或创建研究专题。需要登录、暂时打不开的链接也能留存，但不会产生虚构摘要。

**从已有素材开始研究，再继续**：进入详情，先看原件、关注片段和原话。需要深入时建立或关联专题，填写当次问题，点「交给 Codex 继续研究」。复制到同一项目的 Codex 聊天，明确要求分析；剪贴板不可用时手动全选复制或下载文本。Codex 依据 ID、版本和阶段记录读取、研究、受控回写并回读。回到网页点「重新加载」查看新阶段。新聊天仍可用同一交接继续，候选与未知不会自动变成已采用。

收藏支持内容及用途多标签、来源、后续备注、原话修正历史、轻量文字/时间/图片局部说明、关联多个专题、归档及可恢复删除。研究页保留完整图文、历史阶段、对应段落的来源、未知和下一步。搜索覆盖标题、标签、来源、原话、备注与关联研究正文。

未提交的收藏、编辑、感受、备注、关注标记、研究问题和补充附件会保留为当前浏览器、当前网址下的本机草稿；刷新后在草稿提示中选择「恢复」。草稿按数据身份、记录和原版本分别保存，不自动成为正式资料，也不包含在数据库备份中。旧版本恢复后须逐项核对并明确继续；不同标签页的草稿分别保留。提交结果未确认时用「核对并重试原提交」，系统保留完整原内容和提交标识，确认回读后只清理对应的已提交草稿。

文件选择本体不能跨刷新恢复。已登记原件会核对后复用，尚未登记的文件须重新选择；草稿提示会明确说明。浏览器清理网站数据、换浏览器或换网址会影响草稿可见性；存储失败时页面提示保留输入并停止发送无法保存重试标识的修改。

## 素材深研

在本项目 Codex 聊天粘贴专题交接并明确研究问题，通常使用 `$orchestrate-material-research`。总控按需调用传统溯源与声画深拆，形成有定位的图文阶段，保存并回读后回网页重新加载；不自动研究收藏。三项技能、真实文本/Sintel 案例和当前未听音边界见 [深研使用说明](深研使用说明.md)。

## 数据与备份

| 内容 | 位置 |
|---|---|
| 权威数据库 | `素材观察室\data\observatory.sqlite3` |
| 原始附件 | `素材观察室\attachments\`，首次上传时建立 |
| 完整数据备份 ZIP | `素材观察室\backups\` |
| 成果导出 ZIP | `素材观察室\exports\`，首次导出时建立 |
| 受控模块 / CLI | `web\observatory\` |

以上均相对 `D:\codex\小陌的学习系统`。网页底部「数据位置与备份」显示实际身份和绝对路径；CLI 从任何工作目录调用都定位同一默认库。读取缺库明确报错，不静默创建空库；日常不要重新执行 init。

网页可建立并下载完整备份；也可运行：

```powershell
node 'D:\codex\小陌的学习系统\web\observatory\cli.mjs' identity
node 'D:\codex\小陌的学习系统\web\observatory\cli.mjs' backup
```

完整备份包含 SQLite 在线一致性快照、全部登记原件（含软删除或暂时无引用的附件）、完整待登记原件、数据身份、结构与 SHA-256 清单。它不含应用源码、模型凭据、其他系统或正在上传的临时文件。将下载的 ZIP 留一份在其他可靠位置；不要随手复制活动数据库单文件当作完整备份。

详情或专题的「导出 Markdown 与附件」提供可阅读的全文、原话及历史、来源、未知、版本和相对附件引用。导出适合阅读或交给创作工作流，不能代替完整库备份。恢复只到全新隔离目录并验证，不自动覆盖正式数据；操作见 [维护说明](维护说明.md)。

正文 Markdown 中真实的 `attachment:ID` 图片和链接也会收集到导出包，包含全部历史阶段；代码示例保持原文，未登记或含不安全路径的附件引用明确报错。原始数据库与 JSON 正文保留原引用。2026-10-01 两项优先修复及启用步骤见[修复验收](../验证/素材观察室/优先修复-20261001-230131-6038f1/修复验收.md)。

## 附件与研究边界

| 类型 | 第一版接受格式 | 单文件上限 |
|---|---|---:|
| 图片 | PNG / JPEG / WebP / GIF | 20 MiB |
| 视频 | MP4 / WebM | 250 MiB |
| 音频 | MP3 / WAV | 50 MiB |
| 文字 | TXT / MD | 5 MiB |
| 文档 | PDF | 20 MiB |

上传检查签名、大小、完整性和哈希，先写完原件再登记；本地媒体检查使用现有 FFmpeg/FFprobe。图片、支持的音视频可预览与下载；HEVC MP4 可保存和下载，会明确提示未声明浏览器播放能力；PDF 第一版提供下载，只核对头尾，不声称已理解全文。格式检查、图片显示和视频播放都不能代替实际内容研究。

链接不会自动全文提取，不提供 OCR、ASR、平台收藏采集或网页 AI 聊天。离线仍可浏览、编辑、搜索和导出已有数据；Codex 联网研究与模型请求仍取决于当时工具和额度。删除与解除引用为可恢复操作，第一版不物理清除共享原件，附件可能继续占用磁盘。
