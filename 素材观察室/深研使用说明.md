# 素材深研：使用与能力边界

2026-10-01，小陌授权把素材研究落实为项目内的总控与两个专业技能。收藏仍是轻量入口；只有明确要求研究时才启用。正式数据继续使用原素材库、记录 ID 和 schema 2，不另建研究数据库。

## 从哪里开始

在[素材观察室](http://127.0.0.1:8787/observatory/)保存素材，进入已有或新建专题，复制“交给 Codex 继续研究”的交接。粘贴到本项目聊天，并写出关注点，例如：

> 使用 $orchestrate-material-research，先核对这条精卫文字的正文、旧注和后世解释，再讨论可借用的形式感觉。

> 使用 $orchestrate-material-research，深拆这段视频 00:14—00:22 的动作与空间。能实际听到原音再分析声音；保留证据缺口。

问题足够明确就开始读取和研究；缺口会改变路径时一次只问一个关键问题。收尾保存新阶段并回读，网页点“重新加载”查看图文；下次凭同一 ID、原件与停止处接续。初始吸引点、用户原话、旧阶段与未提交网页草稿保留。

## 三个项目内技能

| 技能 | 实际职责 |
|---|---|
| [orchestrate-material-research](../.agents/skills/orchestrate-material-research/SKILL.md) | 确定贴题问题、范围、证据深度、停止条件，按需组合专业模块，核验图文写回与接续 |
| [research-traditional-sources](../.agents/skills/research-traditional-sources/SKILL.md) | 原文与白话、版本及时间层次、注疏和改编、器物/民俗依据、争议与反证 |
| [analyze-audiovisual-material](../.agents/skills/analyze-audiovisual-material/SKILL.md) | 可见画面、可听声音、合看关系、动作空间、光色、剪辑与节奏；准确定位，区分观察与解释 |

通常只指定总控；明确只做溯源或声画细拆时也可直接指定专业技能。它们与原七项学习技能分工不同，研究成果不自动生成学习进展，也不替正式创作流程完成剧本。

## 证据和图文如何保存

沿用已有阶段的 paragraphs、sources、sourceRefs、attachmentIds、limitations 与 nextStep。原文/所见所闻、文献及他人解释、当前分析、创作候选、未知分别标识。专业分析与创作联想都采用现有 ai_hypothesis 类型，由小节标题和推理依据区分，不更改旧成果结构。

重要判断定位卷叶/文件行、原页或实际时间码。两个电子转录字不同，未看原页不能宣布古本异文；自动切点不是完整镜头表；ASR 不是已经听清的声音。作者意图缺来源时保持未知。原图、原片帧、自制示意与推测图分别标记，保留出处、许可及改动说明。

新增图片与原件用受控 `import-attachment --file` 登记、核哈希及回读后引用真实 ID。总控的 `prepare_stage.mjs` 只准备一份不可覆盖的提交文件，随后仍由原 CLI `submit-stage` 执行。身份、专题版本、所据素材版本与幂等收据照旧；版本冲突重读合并，不覆盖历史。详见[共同读写规则](共同读写规则.md)和[技能写回规程](../.agents/skills/orchestrate-material-research/references/阶段写回协议.md)。

## 阅读成果先让人看懂

2026-10-02，按小陌对上一版“简介太短、排版单一”的反馈改为独立预览与自足概要。收藏卡片的短介绍只服务辨认素材；详情概要用连贯白话说明已核内容，篇幅由材料与证据决定，不按卡片长度压缩或凑字。故事交代有来源的人物、起因、经过、转折及结果；片段和物件按实际情境适配，缺失动机、结局或完整剧情不编补。

主体按理解顺序连续阅读：内容概要、原文与白话/截图与说明、专业分析及创作候选、必要考据。章节按意义组织，图文就近，长文用轻目录。证据类型仍可见，来源轻引用可定位；完整来源和详细方法后置展开，核心正文不全部折叠。读者验读能否复述已知内容、区分事实/解释/联想/未知；UI节点通过不等于小陌满意或学习有效。

有正文的新阅读阶段将前两段heading严格写为“收藏预览”“内容概要”，沿用schema2，不新增字段。可选“方法与读取记录”标记作者明确组织的末尾方法组，网页合为一个可展开区；来源回跳会打开对应组。没有标记时保持连续全文；只记停点的空正文暂停阶段无需编造概要。旧首段“这份素材讲什么”及更早成果继续兼容。详见[阶段写回规程](../.agents/skills/orchestrate-material-research/references/阶段写回协议.md#渐进阅读格式)。

精卫与Sintel的同一正式专题现为v4、各保留3阶段。概要已核对来源并经过无前序稿件背景的模型复述评审，正式桌面和窄屏另有真实浏览器验证；该评审不冒称真人用户测试。原始收藏感受、素材v1、全部旧阶段及11原件未改，没有新增外部研究、重新转录、审听或连续看片。Sintel仍暂停，精卫电子转录差异仍不升级为古本定论。[本轮全文与验收](../验证/素材观察室/概要与长文-20261002-55e208/概要与长文验收.md)。前一轮v3记录保留在[阅读体验验收](../验证/素材观察室/阅读体验-20261002-1a46c5/阅读体验验收.md)。
