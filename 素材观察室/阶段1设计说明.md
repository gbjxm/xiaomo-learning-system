# 素材观察室：阶段 1 设计说明

> 历史设计记录。阶段 2—5 已完成；实际使用、接口和验证以 [README](README.md)、[共同读写规则](共同读写规则.md)及[验收记录](验收记录.md)为准。本文中的“尚未接入”“未初始化”等仅描述阶段 1 当时状态。

日期：2026-10-01。依据：小陌已确认的完整需求、阶段 0 方案与本轮阶段 1 授权。

## 本轮边界

素材观察室从本地新建，不接手、不恢复、不等待云端原型；沿用现有学习终端。阶段 1 只定义数据、受控读写入口并制作三个页面的结构预览。正式 HTTP 接入、真实网页与 CLI 闭环在阶段 2 进行。

本轮不迁移已有数据，不改比赛模块、知识树或创作工作流，不增加网页 AI 聊天、费用、依赖或账号权限，不把演示当成学习活动或真实收藏。正式素材数据库尚不初始化。

## 最小关系

```text
素材条目 ← 专题与素材关联 → 研究专题 → 阶段记录
   ↓                           ↓
原始输入、原话、备注、附件     问题、范围、研究状态、成果与接续
```

素材独立存在，保存时不要求专题、研究问题、标题或标签。专题仅在用户选择研究或组织材料时建立。关联保存稳定 ID，同一素材可服务多个专题，原始输入与附件不复制到专题。

| 对象 | 必要内容 | 生命周期 |
|---|---|---|
| 素材 | 稳定 ID、版本、原始输入及来源、初始原话感受、当前修正与历史、后续备注、标签、关注片段、附件引用、收藏时间 | 在收藏、归档、可恢复删除之间变动 |
| 专题 | 稳定 ID、版本、当前问题与范围、关联素材 ID、研究状态 | 草稿、研究中、暂停、阶段完成、归档 |
| 阶段记录 | 当前关注点、已确认内容、候选方向、暂放下方向及理由、未知、下一步、正文段落、图文参考与引用来源、所依据材料的版本 | 增加阶段记录并保留旧阶段；专题的阶段完成不结束素材生命周期 |
| 附件引用 | 稳定标识、受限本地路径、类型、字节数、SHA-256、原始文件名与许可状态 | 关联记录软删除不物理删除共享附件 |

原始内容与初始感受独立保留。修正感受形成带时间和作者类型的历史，允许对照修改前后；后续备注不顶替原话。Codex 的分析与成果进入研究记录，不改写用户原始输入和感受。

格式仅作为辅助筛选。内容与用途采用自由多标签，允许未分类；AI 标签建议属于待采用建议。

## 来源与研究段落

每份来源有稳定来源 ID、名称、实际查阅位置、访问或核实范围及许可状态。研究正文以可定位的段落或观察项组织，每段可引用一个或多个来源，并注明具体段落、页码、馆藏位置、时间码或图像局部。来源目录提供反向定位，能看出支持了哪一段。

必须区分直接观察、来源事实、作者解释、AI 假设、用户感受与未知。仅保存一个链接不生成分析完成状态；用户回忆不补造原视频和作者。生成或自制示意必须标注，不能作为史料证据。

## 三个页面

1. **收藏列表**：快速输入链接或文字，可选填写原话感受；浏览、搜索和筛选，未分类条目可找到。收藏动作只创建素材。
2. **素材详情**：原始素材、关注片段和原话感受在上；来源、标签、备注和专题清楚可达。研究默认显示摘要与入口，完整报告在专题页。
3. **专题研究**：问题、关联素材、阶段记录、完整图文成果、具体来源、未知与下一步；已确认与候选分别显示，提供复制交接入口。

结构预览位于 [预览页面](../web/设计提案/素材观察室-阶段1/index.html)，全部使用演示资料。操作仅改变当前页面内存，刷新重置。页面演示、隔离数据库原型与正式数据库是三个不同层级，不宣称已经同步。

## 两条路径

- **只收藏**：输入一个链接或一句文字 → 可选记下感受 → 保存演示素材 → 在未分类列表或搜索中找回 → 查看详情。没有自动建立专题或启动研究。
- **研究与接续**：从已有素材详情明确选择开始研究 → 建立或关联专题 → 查看演示阶段记录与成果 → 查看或复制交接文本 → 在后续真实闭环中由 Codex 读取当前持久记录、写回并回读。

预览中的研究内容、来源和采用状态均有演示标识，不当成小陌实际感受、真实考据或已采用创作方向。

## 版本与功能隔离

本次开发运行版本为 Node 24.15.0，使用内置 node:sqlite；不升级环境。存储模块按需加载 SQLite，并返回结构化加载/版本错误。正式终端阶段 1 保持未接入，观察室的失败不会影响学习功能。

阶段 2 按路由加载观察室；原学习启动不导入观察室依赖。运行版本不足时只提示观察室不可用，保持学习功能。兼容矩阵和网页聊天模型不在本轮扩展。

## 阶段 2 必须验证

- 网页服务与独立 CLI 进程使用相同磁盘库与数据库身份。
- 旧版本回写不覆盖网页的新修改；来源材料变化也能发现。
- 重复提交不重复创建成果，提交失败不显示成功。
- 数据库锁等待、回滚和重试提示正确，原数据保留。
- 刷新与服务重启后仍能读取，错误路径不能误建空库。
- 真实新 Codex 会话通过阶段记录接续；新进程读取测试另行报告。
- 正式路由接入后的原学习功能回归；比赛模块保持原样。

真实新会话不能实际启动时，留下人工步骤和未验证状态，不用模拟代替。阶段 1 的内存页面、API 导出适配和隔离单进程检查不证明以上闭环已成立。
