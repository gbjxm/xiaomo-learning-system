# 自然学习记录：第二阶段流程建设

日期：2026-10-05。范围依据：小陌要求完善现有学习技能，打通看课、看片时的自然表达、正确保存和网页查看，随后检查创作接续、学习接续、收藏与研究。本方案记录本轮做法，实际启用与验收以交付记录为准，不把方案或隔离演练当作本人学习成果。

## 本轮要解决的问题

四岛已共用“我的内容”，学习也已有七项技能与正式提交器；缺口是自然记录仍被分到不同入口，纯笔记容易经过任务流程，普通网页聊天没有与观看、创作保存接通。现有学习活动虽留了原话，没有任务的笔记也不一定在网页中可见。

本轮保留七项能力：总协调、路线、时间、讲解、练习、能力判断、复盘。在总协调前置轻量记录分流，仅按实际需要调用专业技能，不要求用户管理岗位或完成记录表。

## 共用流程与归属

自然表达 → 查已有对象并核对身份 → 准备受限动作 → 原保存层提交 → 回读回执及条目 → 在网页查看、下次沿同一编号继续。

| 内容 | 保存与接续 |
|---|---|
| 课程笔记、疑问、本人理解 | 原学习提交器以 note 保存到学习记录，无强制 taskId；原话与 AI 回应分层，网页展示同一条目 |
| 观看经历、感想、进度与重看 | 原 ContentStore 与唯一观影台账，沿同一 W 编号保留后续经历 |
| 创作想法与个人尝试 | 原 ContentStore 与“我的内容”文件，保留补充及更正版本 |
| 学习安排、实际结果、能力观察与复盘 | 原学习任务与提交器，仍按目的、帮助条件、观察点及实际证据接续 |

统一 intake 由网页和 Codex 共用；技能协议集中在 [自然记录与接续](../.agents/skills/orchestrate-personal-learning/references/natural-recording.md)，不在七份技能里复制整套参数。记录不自动变成任务、学习成果或正式项目；片名、原话已经足以起步，未提供的日期、课次、进度和版本保留未知。

保存原话、AI 分析与候选；本人经历、材料引用、推荐和假设分别处理。当次明确不保存就不提交。来源路径或转写不证明看听过媒体，网页收到模型答复不等于保存成功。恢复时先查回执、原对象和版本，不能重建一份相似记录冒充续接。

## 参考来源与本地取舍

本轮只借鉴公开的一手流程与接口设计，代码和技能为本项目自行适配；没有安装第三方技能、连接外部笔记服务或上传个人资料。没有复制外部 skill 正文或代码。

- [OpenAI Notion Knowledge Capture，固定提交](https://github.com/openai/plugins/blob/5fd93af4cd0c623e020d0cc7e9ce178b4ac1f70f/plugins/notion/skills/notion-knowledge-capture/SKILL.md)：借鉴先识别内容、查旧条目、再创建或更新并返回入口。事故复盘式的严重程度、根因和行动项不适用随手笔记，未采用。
- [Basic Memory Capture，固定提交](https://github.com/basicmachines-co/basic-memory/blob/194afe165b3e7676496aaa53b70e39a78ea5aa4f/skills/memory-capture/SKILL.md) 与 [Continue](https://github.com/basicmachines-co/basic-memory/blob/194afe165b3e7676496aaa53b70e39a78ea5aa4f/skills/memory-continue/SKILL.md)：借鉴稳定身份续接、先搜索再读正文。其整篇重写和删去旧内容不用于本人原话，本地保留更正历史。
- [Basic Memory write_note 校验接口](https://github.com/basicmachines-co/basic-memory/blob/194afe165b3e7676496aaa53b70e39a78ea5aa4f/src/basic_memory/mcp/tools/write_note.py#L186)：借鉴预期校验值和保存结果回传；该接口本身不保证幂等，本地另用请求标识去重、未知结果查询和写后回读。

本地领航对照来自 `navigation-connection.json` 指向的 `navigate-personal-development`：复用先接住表达、记录独立于行动、原话与解释分层、版本核对与原系统权威的原则，不复制人生路线或资源容量对象进入学习系统。

## 验收与后续顺序

隔离验证应覆盖：课程笔记无任务可见、只记片名、补充同一作品、原话与 AI 分层、身份不明保留未知、只聊不保存、引用和假设不误写、重复请求不重复保存、失败可恢复，以及 Codex 与网页互相读到同一条目。普通笔记不能修改最近学习任务或能力依据。

随后检查创作接续、学习接续、收藏与研究的现有路径，明确已修复、验证范围和仍需用户实际使用观察之处。本轮不把结构检查、模型演练或文件存在说成真实学习收益。

小陌随后澄清“经济”是“第三阶段”的输入错误。完成本轮自然记录与三条接续检查后，再处理第三阶段的共享背景、跨系统对象关联、结果回流及帮助质量；本轮没有财务模块建设范围。
