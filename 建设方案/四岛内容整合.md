# 四岛的个人内容整合

2026-10-05。小陌已采用：保留主岛、故事、影像与后期四岛，重复的创作、练习、看片和内容回看入口通向共享的“我的内容”。默认展示全部最近内容，可切换“创作与想法／观看记录”。本文件记录本轮已授权范围；最终运行情况以交付验证为准。

## 使用与边界

- 同一条创作可以包含想法、文字与练习版本，从不同岛进入仍接着同一条内容；岛屿是进入视角，不再要求分别登记。
- 自有故事、分镜和节奏练习继续可用；需要时在共享内容里打开相应工具。课程、学习向导、安排、休息与生活旅程保留原分工。
- 电影、短片、电视剧和动漫共用观看记录。仅片名和观看自述也可留下；感受、集数、日期与版本均可后补。未知日期不自动写成今天，记录不等于看完、掌握或有学习任务。
- 主要由自然交流整理和接续，网页支持直接浏览、记录与修正；不用先填完整表单或每次分析。
- 正式影视工程、素材和领航灵感原件不搬迁。共享页面可以显示来源与引用，原记录、本人感受、AI 判断保持区分。

## 当前需解决的具体问题

原四岛已共用练习和看片程序，但练习草稿、看片草稿和书签按岛分开。主岛练习与影像岛还会分别保存同一类模板的草稿。原看片页面要求感想非空，不能只留片名；界面书签也没有自动成为正式观影台账。

本轮实现共享入口与列表、长期保存、同条更新和版本找回、看片轻量登记；保留原草稿和历史入口。界面状态继续只负责接续，长期内容不塞进有容量限制的 UI 文件。

## 数据职责

- 观看事实沿用 `运行记录/观影记录.md`，保留已有 W 编号、原表及其不确定信息。受控接口追加新观看或原作品的新经历／修正。
- 新的个人创作、想法与练习版本归学习系统的 `运行记录/我的内容/`，不替代影视工作流的正式工程。
- 既有学习任务仍由原学习后台维护；旧界面书签／草稿保留来源身份，不自动变成已完成作品或能力证据。
- 原素材、信息与领航数据不合库，不把一次浏览、代码检查或演练记成学习经历。

## 本轮验收重点

1. 四岛对应入口进入同一批内容，默认全部，可按两类切换。
2. 新留一个想法，保存后从另一个岛找到并继续同一条；修改后旧版本仍可查。
3. 只写片名也能记录，电视剧停止集数可后补；同一作品的后续记录使用原身份。
4. 原练习工具可用，保存并重新打开后恢复同一版本；原课程和学习接续继续可达。
5. 旧片单与旧草稿可找回；无模型也可查看和保存，错误、冲突和重复提交不丢原话。
6. 正式数据只做必要变更；写入验证在隔离副本，启用前后核对并发修改与资料保护。

此项是第一阶段的主要收尾整合，并承接第二阶段的实际使用反馈。跨系统自动安排、自动深研和自动制作仍按后续具体需要讨论，不由本次记录触发。
