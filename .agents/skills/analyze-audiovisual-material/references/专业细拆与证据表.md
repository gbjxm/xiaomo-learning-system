# 专业细拆与证据表

用于本轮问题需要更细的镜头、声音或关系分析时。选择能改变判断的维度，不把下面项目全量填表。

## 画面：从描述到机制

先定位某一画面中的可见位置与动作，再看同镜前后或邻镜如何变化。

| 维度 | 需要观察什么 | 解释时的边界 |
|---|---|---|
| 动作与表演 | 头眼手身体的方向、动作起止、停顿、人与物的接触、动作是否改变位置或关系 | 不凭表情推断真实人物心理、生平或演员方法；角色处境须有文本/成片依据 |
| 空间与调度 | 前中后景、距离、遮挡、路径、入口出口、朝向、视线与轴线、镜头间空间能否重建 | 平面图是依据有限的分析示意，隐藏空间与真实尺寸不补作事实 |
| 构图与观看 | 人物/物体占画比例、明暗色彩重心、空白、边界、深度、前景遮挡、焦点 | 能描述视线引导条件；未经观众检验不保证每人体验相同 |
| 摄影与运动 | 景别、角度、画面视点、取景变化、相机与对象的相对运动 | 无连续片段不判摇移跟升降；动画镜头不臆断真实器材与实体灯光 |
| 光色与质感 | 亮度层级、方向线索、硬软边缘、色相冷暖、表面反射、纹理与局部变化 | 不把颜色固定对应情绪，不仅凭成片声称具体光源/色温/材质或文化象征 |
| 剪辑与信息 | 切换前后保留/改变了什么，动作接点、视线、空间线索、空镜/字幕、时间省略 | 不机械以180/30度规则打分；须结合观众当前需要的信息 |

一个细拆段落可沿“证据A → 变化B → 观看/信息影响C → 条件与备选解释D”展开。例如同一对象从较大画面占比变成小尺度，不足以直接称‘孤独’；先核实空间、关系、前后叙事与声音，再把孤独标为可能体验。

## 镜头组：分析跨镜的事情

根据当前问题记录镜头开始/结束、持续时长、当前信息、变化、与前后镜的交接、声音位置。一个镜头可以承担多项任务；不要给每镜强造戏剧转折。

- 基准：这一组让观众先知道什么或先看谁？
- 变化：景别、视点、动作、遮挡、光色、切换或声音在哪一刻改变？
- 保留：人物、目标、轴线、色彩、声响或视觉元素如何让变化仍能被接上？
- 未给：画面省略什么，观众靠什么补全？能否还有其他补法？
- 收束/交接：这一组结束把注意力、问题或感觉交给哪里？

若只抽帧而未连续看，报告“帧间差异”与“候选衔接”，不把动作完整过程、切换类别或准确节奏称作已审看。逐帧定位的切点与语义镜头组分别判断。

## 声音：实际听取的分层

保留完整原音轨作依据；mono/降采样ASR代理不用于声场与混音结论。

| 层 | 可记录的听取问题 |
|---|---|
| 对白与发声 | 出现/停止、语句与停顿、呼吸、声源是否可见、距离与清晰度；语义转录另行逐疑点核对 |
| 环境与动作 | 风水室内外底声、脚步碰撞等声响的进入、持续、变化；声源不明写未知 |
| 音乐 | 是否有连续/脉冲/重复/停顿、强弱变化、与动作或切换的对应；不能只靠ASR或频谱指认乐器/曲名 |
| 静默与层次 | 接近静默是否相对于之前层次减少、哪个层仍在、观众注意被带到什么；数字静音与感受上的安静分别描述 |
| 空间与加工 | 声源远近、左右、回响、失真等可听变化；具体插件/麦克风/录音方案通常不能确知 |

听取记录应含原文件哈希、区间、原音或代理、具体事件时间、听到的描述、是否复听及疑点。ASR文字即使置信度高也只是模型草稿；公开字幕可能是改写、翻译或平台自动生成，与原音不是独立验证。

## 合看：把关系落在同一时刻

对需要声画关系的区间实际合看，必要时无声重看、离画回听再核对：

- 画面切换是否在声响/音乐重音前后？精确到当前证据足够的程度，不用宽窗ASR时间直接判同步。
- 声音是否先于新空间进入、跨过切换延续，或在画面停住后继续？
- 动作声与动作接触点是否一致，画外声是否改变对空间/人物的理解？
- 音乐脉冲、动作密度、信息释放与切换密度是否同向，还是形成对位？
- 停顿改变的是声层、动作、视点还是信息？长镜内是否已有节奏变化？

关系标签是描述，效果是分析；“导演就是想……”须有查到的作者说明。对位也不天然代表讽刺，音画一致也不天然代表平庸。

## 证据与输出最小检查

1. 来源实际可读范围与每段定位一致，帧号使用零基/一基规则明确；保留原PTS及裁切偏移。
2. 自动切点、ASR、波形、元数据与模型看到/听到的内容分别记录。工具跑完不能替代语义验证。
3. 可见可听事实不混入角色动机、作者意图或文化象征。分析解释说清观察支持的条件与备选解释。
4. 原图、原片关键帧、演示图、推测图分别标；署名、许可和改动说明随成果保存。
5. 每个来源实际支持对应句子；转述的多个网页不是多个独立证据。
6. 重要未知优先于补齐表格；没有听音/合看能力时保存可用画面部分与准确下一步。

## 方法来源

- [PySceneDetect官方仓库](https://github.com/Breakthrough/PySceneDetect)及[检测器文档](https://www.scenedetect.com/docs/latest/api/detectors.html)：候选切换与图像差异算法；不提供影片语义。
- [OpenAI Whisper官方仓库](https://github.com/openai/whisper)及[模型卡](https://github.com/openai/whisper/blob/main/model-card.md)：ASR用途、语言差异与可能生成未实际说出文字的限制。
- 现有 `generate-film-breakdown-report` 的报告专业标准可按需参考“事实/解释/边界、镜头组、镜内节奏”部分。本项目不继承其Kimi外传、专属Vault输出或固定全片报告门槛。
