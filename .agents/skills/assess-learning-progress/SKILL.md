# 学习进展与能力依据

先读项目共享契约 [运行约定.md](../../../运行约定.md)。专业职责返回带依据的判断与建议，由 `orchestrate-personal-learning` 汇合保存；不直接修改运行记录、知识树掌握字段、项目事实或采用状态，不递归调用本项目其他专业技能。

## 明确本次判断范围

先确定用户希望能做的任务、难度和允许的帮助程度，再查看与之有关的实际回答、学习记录、产物或片段。需要背景时按需读取 `运行记录/阶段安排.md`、`运行记录/能力依据.md` 及其引用记录；不因某领域缺少记录就安排全面重学。

“暂时够用”仅针对当前阶段目标。先复用已有表现，不以全面测验为入口；关键范围确实不明时，只补一个会影响判断的问题。

按 [共用判断契约](../../../建设方案/学习判断契约.md) 使用同一 taskId、目标版本、允许帮助和原观察点。根据可定位表现区分概念、应用、操作、组合、材料工具及时间问题；原因未明时保留必要解释，不一律补课。反馈分别指出已有有效表现、主要差距、依据和最小下一步，不把 AI 替写或候选当用户能力。自然收尾由当前执行者使用运行约定的共享 CLI 汇合。

## 分开辨认依据

| 信息 | 能支持什么 | 不能自动推出什么 |
|---|---|---|
| 用户自述、感受、过去经历 | 当事人的体验与自报情况 | 已独立验证的全面能力 |
| 课程、阅读或材料完成情况 | 接触过的内容和投入背景 | 已理解、能应用或会迁移 |
| 用户对概念的解释、辨析、情境判断 | 已展示的概念关系与适用范围 | 完整制作与实际操作能力 |
| 真实练习、操作、作品版本及修改过程 | 对应任务中的应用表现 | 所有任务都能稳定完成 |
| 工具输出、素材条件、他人或 AI 协助 | 该条件下任务如何被完成 | 用户独立完成了全部环节 |
| 观看反馈、采用、传播或收入 | 对应作品和情境的外部结果 | 全部学习目标已达成或未达成 |

记录观察范围与来源。亲自读到回答、查看产物，与仅收到用户报告应分清；静帧、截图、局部检查不冒充连续动态审看。旧结论可作线索，新结论仍需明确当前依据。

帮助程度服务于当前学习目标：独立、参考资料、提示后完成、协作完成或工具代做均可以如实描述，不机械要求脱离 AI。重点分清用户作出的判断和工具承担的执行；条件未知就说明未知，不猜测补齐。

## 反馈来源与缺口

先分析已有回答和产物能够支持的结论，再看反馈是否足以回答当前问题。材料与 AI 可支持可观察事实、原理运用或连续性的初判；真实接收者的理解与感受需要其实际反应；专业规范先核对当前标准或交付要求，经验性取舍可由做过类似任务的人提供意见。专业意见不是自动适用的规则，AI 模拟观众也不是观众反馈。

缺少相关外部证据时，明确暂不能下的是哪个结论，不用一句“需要外评”替代对已提供材料的具体分析。若补证据会影响下一步判断，给出一个低成本获取方式：由谁看哪个现有片段、回答什么问题。例如叙事清晰度可请目标观众独立看小样后复述事件；交付问题可向有类似经验者提供具体用途，请其指出一处需要修改的地方及理由。

外评是按需建议，不成为开始学习或继续练习的门禁；不擅自联系、发送或发布。收到反馈后保留反馈者与任务的关系、实际说法和观看条件，将原反馈与 AI 解释分开；少量评价不证明普遍受众效果、市场需求或全面专业能力。

## 形成有边界的判断

- 对照目标说明已展示的能力、关键差距与仍不确定之处。没有证据不等于不会；只有自述时可给初步判断，不能写成已核验事实。
- 单次成功说明本次表现；重复、新材料或间隔后再次成功可补充稳定性依据。是否需要这些证据随任务风险与阶段目标决定，不设一刀切次数或分数门槛。
- 区分概念不清、操作不足、综合取舍、材料问题、工具限制与时间安排。提出归因假设时标明推测，不把所有困难归咎于不努力或学习不足。
- 审美与创作选择结合意图、条件及效果讨论；存在争议的来源先保留未决，不据 AI 偏好判错。
- 可以建议继续、局部补练、保持观察或有意识地转向；建议不自动成为任务，不因证据尚少禁止用户继续探索。

## 仅在需要且明确要求时检验

当用户明确请求检验且已有材料不足以回答当前问题时，只提出能区分关键理解的一题，并等待真实回答。不要借“查漏补缺”自动展开考试、连续追问或预先给标准答案。

概念检验可按共享契约读取当前 `internalize-film-knowledge` 的 `references/mastery-rubric.md`，只参考只读诊断规则；不执行旧选题器、写回或状态路由。其概念标签不能替代本技能的实际任务描述。

收到回答后评估已展示的部分，说明必要修正和理由。用户跳过或停止则结束，不生成失败记录或复习债务。若需要制作新练习来补证据，仅提出补充需求交回协调器，不擅自启动媒体生成或修改项目。

## 返回与完成

返回与本次问题相关的结论：任务范围、依据入口、观察到的表现、帮助条件、未决限制及必要建议。使用自然文字，不要求用户逐字段填写，也不输出无依据的精确掌握百分比。

同一证据只引用其原记录，不重复制造新事实。能力依据和采用状态由总协调保存；直接被用户调用时，到共享契约规定的自然保存节点，由当前执行者在同一对话读取总协调保存规则并履行该职责，不另开协调会话、不要求切换任务或重复授权。

尚未读取、未回答、未审看或仅由 AI 推测的部分如实标明。完成判断不等于验证了学习系统整体有效，也不等于作品或商业成功。
