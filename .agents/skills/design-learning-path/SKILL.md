# 学习路线与材料选择

把宽泛方向转成能够接续的学习路径，让每段学习都有用途和可观察的进展。默认结合影视 A/B/C1/C2/D/E 的能力与实际任务，允许跨专业组合。

## 读取与职责

- 使用前读取项目根的[运行约定](../../../运行约定.md)，按其中的证据、写入和跨系统约定工作。
- 按本次需要读取[个人情况](../../../运行记录/个人情况.md)、[当前状态](../../../运行记录/当前状态.md)、[阶段安排](../../../运行记录/阶段安排.md)和[能力依据](../../../运行记录/能力依据.md)。先用已有信息，只补问真正影响路线的缺口，不重新发整轮问卷。
- 专业环节返回路线、依据和调整建议；个人目标、安排、能力状态和采用结果由 [orchestrate-personal-learning](../orchestrate-personal-learning/SKILL.md) 的协调环节统一保存。直接点名本技能时，到自然保存节点由当前执行者读取该技能的保存规则，在同一对话履行保存职责，不另开协调会话，不要求用户切换或重复授权。
- 具体作品以创作项目当前文件为准；知识材料引用知识库原位置。学习路线不能改变正式项目目标、岗位交接或制作授权。

## 设计路线

1. **明确本阶段希望能做的事。** 将“学习剪辑”等宽泛方向转成当前有用的任务，例如能安排一段对话的信息顺序并说明取舍。分别说明用户表达的目标与 AI 提出的细化建议。
2. **定位起点。** 综合实际产物、当次解释、已记录表现和用户自述。没有表现记录时保留未知，不据空白要求重学；自述和看完课程也不单独证明已掌握。
3. **选择适量先修与顺序。** 只列会影响下一步的关键依赖，说明缺口会造成什么困难。先修关系用于解释选择，不形成硬性通关门禁；基础学习与应用可以交替。
4. **选材料并说明用途。** 优先检查正在使用的课程、文章、作品和已有知识入口，避免为每个目标另开一套资源。必要时查找新材料，核对原始来源、适合程度、所需投入与可访问性；付费、不可访问或只读过介绍的内容要如实说明，不自动购买、下载或安装。
5. **连接应用与够用依据。** 为阶段目标配一个合适的观察或应用方式，需要细化时向总协调返回练习需求。说明在什么任务范围、什么帮助程度下能够继续前进；剩余问题可留作后续回访，不要求先彻底精通。

对长期方向只展开到当前能合理判断的程度。保留本阶段主线，也允许用户明确选择新的方向；说明改变的收益与当前内容如何处理，避免每天重新生成互不相接的课程清单。

用户尚不清楚先学什么时，利用已有意图、正在做的任务和少量相关材料，比较当前最有用的起点并给出推荐理由；必要时只询问一个会改变取舍的信息。可以先选一个低成本的小任务来观察实际卡点，也允许先学一小块基础内容，不把综合练习作为所有学习的前置门槛。试探性起步不等于已确定长期方向。

## 返回结果

按任务复杂度自然表达，至少让统筹和小陌看清：

| 内容 | 需要说明 |
|---|---|
| 阶段目标 | 希望完成什么判断或任务，服务哪个实际目的 |
| 材料 | 可定位的入口、选它的理由、需要关注的范围 |
| 必要先修 | 已有依据、关键缺口及其影响；没有就不强加 |
| 学习与应用 | 合理顺序，何时观察、练习或进入作品 |
| 阶段够用依据 | 需要看到的表现、允许的帮助、判断适用范围 |
| 下一步 | 当前可以开始的一小步，及何种反馈会改变路线 |

已有路线局部调整时，只返回受影响部分、调整原因和保留内容。材料阅读量、学习时长与能力证据分别描述；不生成无依据的掌握百分比。

## 与其他能力衔接

依 [共用判断契约](../../../建设方案/学习判断契约.md) 返回同一任务与目标版本、允许帮助、原观察点和什么结果会改变路线。先使用已有课程和真实表现；材料选择说明与当前目的的关系。更换时间安排不改变阶段目标，AI 提出的新主线仍为候选。直接调用后的自然保存遵守运行约定的共享 CLI，不自行覆盖个人文件。

- 时间容量与日期分配由总协调按需衔接 [plan-learning-time](../plan-learning-time/SKILL.md)，不在此预设固定学习比例。
- 需要针对性或综合练习时，返回目标、已有材料、允许帮助与投入条件，由总协调按需衔接 [design-learning-practice](../design-learning-practice/SKILL.md)。专业技能之间不互相递归调用。
- 需要专业知识时，先读相关现有技能及其当前入口，只取本次所需来源；不为设计学习路线遍历整个知识库。
- 返回给统筹时区分已经确认的目标、路线建议、真实依据和待了解部分。用户明确请求的安排或方向变化可按运行约定保存；AI 自行提出的新方向保持候选，不自动建立新的长期安排。
