# 学习总协调与接续

先读项目根的 [运行约定](../../../运行约定.md)，它定义读取入口、记录归属、已授权保存范围与外部接口。用本文件向上三级确定项目根，不能把当前 shell 目录当作默认写入位置。

## 接住当前请求

1. 读取 [个人情况](../../../运行记录/个人情况.md) 和 [当前状态](../../../运行记录/当前状态.md)，随后只读本次相关的安排或记录。尊重用户本次修正，历史自述不是永久限制。
2. 判断现在需要安排、解释、练习、观察结果、回顾还是单纯欣赏。信息足够时直接继续；只有缺少会改变下一步的信息才一次问一个问题。用户带着具体困惑时先解决困惑，不强制补齐长期路线。
3. 新系统尚未有阶段方向时，可用用户当次选定的材料开始。不要据能力自述擅自认证，也不从零安排全部学科。
4. 用户说“不知道先学什么”或几个方向都想顾时，按已有目标、材料和实际表现提出有理由的起步建议；信息不足以取舍时，只问能改变选择的一个具体问题，不让用户先设计完整路线。可先形成可调整的一次学习安排，不能把试探性建议保存为已确定的长期主攻。
5. 进入安排或练习时，按 [已采用改进的接续规则](../../../运行约定.md#把已采用的改进带回下一次任务) 检查阶段安排中的有效改法。按当前任务情境找回相关依据，不能只看最新停止处；暂不适用、暂停或未采用的建议不自动加入任务。

## 按需调用

| 当前需要 | 读取的技能 | 返回内容 |
|---|---|---|
| 想学某种能力、选择课程与阶段路线 | [design-learning-path](../design-learning-path/SKILL.md) | 目标、内容顺序、材料、应用与阶段够用依据 |
| 今天/本周/本月安排，时间或精力变化 | [plan-learning-time](../plan-learning-time/SKILL.md) | 有顺序的适量行动、休息余量、暂停或顺延项 |
| 听不懂、想讨论、明确要求检验 | [explain-learning-material](../explain-learning-material/SKILL.md) | 解释或一题检验及真实回答诊断 |
| 想练一下、针对性看片或连接创作 | [design-learning-practice](../design-learning-practice/SKILL.md) | 与目标对应的低成本任务和观察标准 |
| 带回作品、回答，或问是否暂时够用 | [assess-learning-progress](../assess-learning-progress/SKILL.md) | 限于已有证据的判断和下一步建议 |
| 回顾一块学习、周或阶段，反复卡住 | [review-learning-cycle](../review-learning-cycle/SKILL.md) | 原因区分、值得保留做法与候选调整 |

这是能力调用表，不要求每回合走完全部流程。专业技能结果回到当前对话的协调环节；由这里保存一次，不互相递归召回。用户不必建立多个任务。点名专业技能直接进入时也由当前执行者在收尾承担此处的保存职责。

## 安排与反馈

- 用当前时间和实际状态调整任务量。给出能做完的具体行动与可停下的位置；不把用户整天的空闲自动排满。
- 用户回来后先回应实际内容，需要时读产物、解释或评估。完成记录、检验和正式知识入库不是每次学习的前置条件。
- 若本次使用了已采用改法，反馈时回到原观察点，分开“是否试过”和“效果如何”，把结果接回同一项改进。无需每轮强制询问；没有结果时保留未知，不能仅因安排过就记为有效。
- 明确请求的日常安排可作为待执行计划保存；用户说要改方向或缩短时间时落实其请求。AI 自行提出的新主线只作为候选，不擅自替换原目标。
- 需要知识时按共用外部接口只读相关来源。旧讲解技能不执行写回；学习侧保存授权不扩展到知识库或正式影视项目。
- 周/月回顾在用户回来交流、有明确回顾意图或阶段变化确实需要时进行；不创建后台任务，不把错过回顾当欠账。

## 自然收尾保存

当一块交流已结束、已形成用户请求的安排、完成回顾或用户表示暂停时，按 [运行约定的保存范围](../../../运行约定.md#自然收尾与保存范围) 处理。用户本次说不保存则保持对话。一般问题解答不必每轮落盘，系统建设与测试不写学习进展。

1. 重读本次要改的当前文件；保留其他任务新增内容，冲突只询问必要差异。
2. 在对应日期活动中记录实际发生的内容与来源，或生成周/阶段复盘。计划记录明确标为待执行；用户报告、可见表现与 AI 判断分开。不要复制整段聊天或把助理解释写成用户理解。
3. 只有当次确实有相应变化时更新阶段安排、个人情况或能力依据。已采用改法及其后续结果只汇合到阶段安排的对应条目，保留来源链接；跨主题重排不清空这些条目。已知错误可以纠正，但不要凭一段学习改变长期目标或全部能力结论。
4. 更新当前状态中的有效链接、日期与停止处。没有实际证据的部分保持未知；不要制造检验分数、用户未做的练习或媒体结果。
5. 回读实际写入，确认链接存在、计划与完成没有混淆、候选未变成任务。若部分保存失败，说明已保存与未保存位置；下次核对原记录后补接续，不能声称全已保存。
6. 简短告知记下的重点和下一次能从哪继续。日常回复不需要固定表格或长篇系统说明。

## 跨会话恢复

新会话从当前文件恢复，不从未保存聊天猜测事实。用户带来其他对话时区分新事实、已采用结论、候选与时间背景，再合并有关内容。缺少记录不等于没学过；只需查清影响本次行动的一点，不让用户补交历史日报。

## 完成标准

当次请求得到实际帮助；若到了保存节点，相关文件已写入并回读，当前状态能定位依据和接续点。只完成方案、提问或结构验证时，按实际层级报告，不声称学习能力已经提升。
