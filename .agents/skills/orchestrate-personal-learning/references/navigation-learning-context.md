# 领航与学习的背景接续

安排学习、选择路线，或作出依赖个人处境的判断时，按需使用领航已明确保存的个人资料和相关已采用方向，减少重复说明。仅留下课程笔记、观看感想或创作想法时，继续走自然记录入口，不为登记增加背景读取、问题或行动。

## 取得本次可用的依据

在本技能所属项目根使用已有学习 CLI：

```powershell
node web/learning/cli.mjs context --input '<请求JSON绝对路径>'
```

助手准备本次请求 JSON；沿用 `message`、`mode`、`requestId`、`history` 及已经核对的 `context`。不要求小陌手填接口字段。`context` 返回同一网页学习入口使用的上下文，领航背景由连接层按请求提供；不另猜原领航路径或自由遍历目录。只检查来源清单时可使用 `sources --input`，同一轮没有相关更新时无需把两条命令都执行一遍。

检查实际返回的 `sources`、`sourceCoverage` 和 `warnings`：来源可获得与已纳入本次上下文分别判断。保留条目身份、来源位置、日期与版本依据；没有返回的内容不能声称已读取。背景读取是只读操作，不创建学习任务、个人记录或采用决定。

领航来源的 `sourceKind` 为 `personal_context`，只作为个人背景，不是课程原文或本轮能力表现；`context` 返回的 `contextSnapshot.sharedBackground` 可用于核对本次读取状态及实际纳入的来源编号。

## 使用与冲突判断

- 本次用户明确提供的时间、精力、意图与更正优先。已足够清楚时直接继续，不重复询问已有条件。
- 领航个人资料仅使用当前有效版本。定向更正后引用现行条目，旧版本保留在原来源历史中，不把旧说法和新说法并列成两个当前事实，也不回写覆盖学习个人情况。
- 带日期的处境或自述保留发生时间。昨日、上周或更早的空闲和精力不能直接换算成今天的时间预算；缺少当下条件时保留假设，只有会改变安排才补问一点。
- 相关已采用领航方向可作为安排与选材的背景。它不自动改变学习任务的目标、目标版本、阶段主攻或采用状态；需要调整时按当前请求和原学习契约处理。领航候选、AI 理解和推荐不能冒充用户采用。
- 默认不读取全部原始旅程，不从日常片段归纳长期人格、能力等级或健康结论。当前请求确需某段经历时，先定位相关原记录并保持原话与 AI 解释分层。
- 读取失败、来源缺失或上下文未包含时，明确说明本次没有取得哪部分；用用户当次信息和已取得的学习资料继续。不能说已经同步最新背景，也不拿旧缓存伪装成当前状态。

## 收尾边界

本步只让学习帮助用上适当背景，不新增跨系统写入或结果自动回流。实际学习安排和反馈仍按原共用 CLI 与自然收尾规则保存；只记录本次确有依据的变化，不另建永久个人背景副本，不把系统建设或接口验证记为学习进展。
