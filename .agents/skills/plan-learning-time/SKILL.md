# 日周月安排与重排

让现有学习方向落到本次能够完成的一步，帮助形成可持续节奏。月或阶段决定方向，周决定推进重点，日或单次决定眼前行动；不要求先有长期计划才能开始学习。

## 读取与职责

- 使用前读取项目根的[运行约定](../../../运行约定.md)。
- 按需要读取[个人情况](../../../运行记录/个人情况.md)、[当前状态](../../../运行记录/当前状态.md)与[阶段安排](../../../运行记录/阶段安排.md)。采用最新用户信息；只问影响本次安排且尚未知晓的条件。
- 按 [领航与学习的背景接续](../orchestrate-personal-learning/references/navigation-learning-context.md)，使用共用学习 CLI 的本次上下文核对当前有效的领航资料与相关已采用方向；不默认翻读全部旅程，也不另存个人背景副本。若本轮已取得相同上下文且没有相关更新，直接复用。
- 专业环节返回安排及调整说明，个人状态由 [orchestrate-personal-learning](../orchestrate-personal-learning/SKILL.md) 的协调环节统一保存。直接点名本技能时，到自然保存节点由当前执行者读取该技能的保存规则，在同一对话履行保存职责，不另开协调会话，不要求用户切换或重复授权；不修改外部日历或其他系统。
- 现有项目任务可作为时间安排的输入，引用真实入口；安排某段创作时间不等于获准修改项目、生成媒体或发布作品。

## 安排依据

- 先理解这次可用的时间窗口、结束条件、精力与打算。时间不明确时可以给出带假设的粗安排，必要时问一个关键问题，不索取完整生活日程。
- 从已采用主线和上次停止处选择重点。用户这次有明确新意图时尊重当前要求，说明与原安排的衔接，不擅自把临时兴趣升级为长期方向。
- 安排具体任务时，按共享契约引用阶段安排中与该情境有关的已采用改进；相似任务已有实际投入或疲劳反馈时据此修正本次估计。更换当天安排不清空改进汇总，未采用的估时建议不变成长久偏好。
- 用户初始自述的前一两小时较专注只是参考。当天状态和实际反馈优先，不把它固化为每日高强度训练长度。
- 有日期的领航状态保留原时间背景，不把旧日空闲或精力当成本次预算；用户已明确今天的时间、精力与意图时直接按这些条件安排。领航采用方向可解释取舍，但不能据此静默改写学习任务的目标版本或阶段主攻。
- 预计耗时包含学习之外的必要准备、切换、回顾及休息。可用时间是容量上限，不是必须填满的目标；给估计留有余量，不用固定百分比填充。

## 三个尺度

| 范围 | 应输出什么 | 控制粒度 |
|---|---|---|
| 月或阶段 | 这一阶段的重点、希望看到的成果、主要活动和回看时机 | 保留弹性，只细化近期可判断部分 |
| 周 | 承接阶段重点的可做任务及其先后、材料与练习的配合 | 按本周现实容量取舍，不平均分配六岗位 |
| 日或单次 | 当前重点、顺序、大致投入、休息与停止处 | 默认自然任务块；用户需要时再排到具体时刻 |

没有月周安排时，直接根据这次意图形成单次安排；把需要后续决定的方向交给统筹，不把补建长期计划作为学习前置条件。没有足够时间信息时给投入范围或顺序建议，不编造精确日历。

## 重排与重新开始

当时间变少、状态下降、材料超出预计或用户中途返回时：

1. 找到已经完成和实际停止的位置，避免重新做已完成部分。
2. 在保留重点的前提下缩小任务、减少可选项，或改成适合当前状态的活动。
3. 明确剩余事项是继续、顺延、暂停还是放下。未完成任务不机械地全部推给明天，也不默认补时、加班或补交记录。
4. 给一个容易开始的接续动作。分心或休息本身不作为道德评价，不推断用户缺乏自律。

需要休息时给可调整建议，允许在自然段落结束处暂停；不默认番茄钟参数、强制计时、屏幕监控或离开对话后的提醒。当前对话中的提醒不代表后台计时正在运行。

## 返回结果

按 [共用判断契约](../../../建设方案/学习判断契约.md) 接收路线或当前任务的 taskId、目标版本和观察点。缩时优先减少任务量、切换和准备成本，说明当前小步能验证哪些部分，不默默降低原阶段标准或更换主攻。任务身份在重排与休息后保留；正式安排与自然收尾使用运行约定的共享 CLI。

让小陌容易辨认当前重点、做事顺序、大致投入、可选项和休息。短安排可以用几句话，复杂安排再用表格，不要求每日固定模板。

同时给统筹以下必要信息：

- 本次安排使用的时间与状态依据，以及仍采用的假设。
- 与阶段/周重点的关系；无长期主线时说明本次独立目标。
- 安排中的轻重、合理停止处，以及缩减或顺延的内容。
- 如有估时偏差或持续疲乏，只返回观察与调整建议，不据此自行改写长期个人偏好。

需要重新选择学习方向、材料或细化低成本练习时，向总协调返回具体需要，由其按需衔接 [design-learning-path](../design-learning-path/SKILL.md) 或 [design-learning-practice](../design-learning-practice/SKILL.md)，专业技能之间不互相递归调用。已有安排够用就直接接续，不为每次启动重复调用全部技能或代理。
