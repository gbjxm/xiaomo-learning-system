# 练习与作品学习

把学习目标转成值得做、负担适当的实际活动。可使用已有素材、静帧、文字、配音占位或版本比较；练习形式应足以观察目标能力，不以成片规模衡量练习价值。

## 读取与职责

- 按 [共用判断契约](../../../建设方案/学习判断契约.md) 沿用当前任务的目的、目标版本、允许帮助和原观察点。先用已有作业或作品找一个能暴露卡点的小应用；不在练习环节另换评价目标。原目标涉及连续声画时，文字或静帧只能覆盖相应子问题。返回同一任务的实际产物、表现和接续；收尾使用运行约定的共享 CLI。

- 使用前读取项目根的[运行约定](../../../运行约定.md)。
- 根据本次问题读取[当前状态](../../../运行记录/当前状态.md)、[阶段安排](../../../运行记录/阶段安排.md)与[能力依据](../../../运行记录/能力依据.md)，必要时读[个人情况](../../../运行记录/个人情况.md)中的投入条件。
- 专业环节返回练习方案、观察提示及收到的结果，不自行认证掌握；个人状态、学习记录和能力依据由 [orchestrate-personal-learning](../orchestrate-personal-learning/SKILL.md) 的协调环节统一保存。直接点名本技能时，到自然保存节点由当前执行者读取该技能的保存规则，在同一对话履行保存职责，不另开协调会话，不要求用户切换或重复授权。
- 用户要求生成练习用文件时，可写入其点名位置；未指定时放在本项目 `练习/`，避免覆盖已有产物。本技能不生成付费媒体，也不默认启动图像、视频、配音或音乐生成任务。
- 正式剧本、素材和时间线仍由创作工作流维护。阅读或引用项目结果前核对当前入口；学习活动和练习产物不等于正式项目采用、准入或修改授权。

## 选择活动

先区分用户当次意图，不把所有看片或创作都转成作业。

- **只留下想法、观看感受或既有尝试：**由当前协调环节按 [自然记录与接续](../orchestrate-personal-learning/references/natural-recording.md) 登记或续接同一内容，不创建练习任务；确有学习问题时再使用当前原文和产物设计必要的一步。内容编号与学习任务身份可以关联，不能互相替代。
- **自由欣赏或休息：**保留自由，不布置观察清单、强制总结或测验。用户事后有发现再讨论。
- **带问题的作品观察：**围绕当前困惑选择一个片段或少量对照，给适量观察方向；首次观看可先感受，再回看具体处理，不默认逐镜登记。
- **针对性练习：**突出当前要练的判断或操作，控制其他变量，方便发现下一步要调整什么。
- **综合练习：**用较小而完整的任务连接故事、镜头、剪辑或声音，说明关键环节如何相互影响，回应“单项会、串起来困难”。
- **真实项目中的应用：**将学习问题对应到实际任务，练习建议交项目当前岗位承接；不抢占作品原有表达和交付目标。

用户已有课程作业或正在做的作品时，先判断它是否已经能提供合适练习，不重复布置另一份同类任务。

## 设计练习

选择能支持当前观察的最省投入形式。用户没有昂贵试错条件时，可以先用文字、已有片段、手机素材、静帧顺序或临时声音观察叙事与衔接，再判断是否需要进一步制作。不要把静态小样的结果外推为动态生成成功或成片质量通过。

每个实质练习说明以下内容，简单时用自然语言表达：

| 内容 | 需要说明 |
|---|---|
| 任务 | 具体做什么，使用哪些真实可获得的材料 |
| 目的 | 这次想练或弄清楚哪项能力，和阶段目标有什么关系 |
| 投入 | 大致时间、必要准备、素材与费用条件；预算未知不默认花钱 |
| 产物 | 完成后留下什么可讨论的结果，已有产物可以直接引用 |
| 观察标准 | 看哪些具体表现，哪些属于事实或连续性，哪些属于意图与审美取舍 |
| 反馈来源 | 哪些判断可据材料初判，哪些需要真实接收者或专业依据；按当前问题选择 |

观察标准在练习前说明，避免看到结果后为了给出好评而改变标准。允许用户与 AI 协作，但明确这次准备亲自练的部分与允许的帮助；不默认所有能力都要脱离 AI 独立操作。

反馈来源与要回答的问题对应，不要求每次同时具备：

- **材料与 AI 初判**：依据原始材料、可定位的画面或参数分析，例如“这个剪点前后，视线指向是否一致”。只评价实际能观察到的部分。
- **真实接收者体验**：判断是否看懂、感受到什么或哪里困惑时，可请符合预期受众的人独立看现有小样，问“你觉得发生了什么，哪一处让你没跟上”，不要先告诉对方想要的答案。
- **专业规范与经验判断**：明确的交付条件先对照当前规范或真实要求；需要经验判断时，可请做过类似任务的人看相关片段，问“按这个用途，哪一处需要返工，依据是什么”。专业意见与规范本身仍需区分。

需要外部反馈时，给出适合的对象、足够短的已有片段和具体问题，供小陌选择；不默认要重新制作昂贵样片、固定找导师或每次外评。暂时没有反馈渠道仍可开始练习，只保留相应效果待观察。本技能不擅自联系他人、发送消息或发布作品；少量人的反馈只说明这些人在本次条件下的反应。

控制练习数量和完成范围，让当前练习有合理的停止点。专项难度逐步增加，但不设置统一分数、强制通关或每日固定练习数量。

## 带回结果后的处理

- 先回应实际结果和用户感受。指出可定位的有效之处、问题及依据，再决定是否建议局部重试，不自动再布置整套任务。
- 区分用户报告、实际查看的产物、AI 判断和仍无法观察的部分。课程结束或文件生成只证明对应活动完成。
- 向统筹返回任务范围、实际表现、使用帮助、产物位置、反馈来源与实际反应、疑问和下一步建议，供能力判断与复盘使用；尚未取得的反馈保持待观察。
- 对于作品比较，说明不同处理如何服务不同意图；不把审美偏好当作唯一正确答案。对于声画结果，只评价本次真正看过或听过的部分。

需要完整可核验的拉片报告时，按用户明确需求使用现有 `generate-film-breakdown-report` 并先读取其入口；普通作品观察不自动升级为报告生产。需要调整练习投入、目标或材料时，向总协调返回具体需要，由其按需衔接 [plan-learning-time](../plan-learning-time/SKILL.md) 或 [design-learning-path](../design-learning-path/SKILL.md)，专业技能之间不互相递归调用。
