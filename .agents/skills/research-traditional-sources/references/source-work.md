# 传统材料的专业核查

只读取与本轮问题相关的部分。以下条目用于改变判断，不要求每次补满所有栏。

## 原文、版本与释义

先固定一个可重找的文本单位：篇/卷、段落起讫、文件、叶面正反或页码。网页“第 65 段”、扫描“第 83 张”和原书“卷三十四叶背”是不同坐标，分别记录，不互换。动态原文件可补访问日期、revision/commit 与内容哈希；拿不到 commit 就直说，不虚构稳定版本。

用四层时间检查错位：

| 时间层 | 要核的问题 |
|---|---|
| 故事设定/传说叙述时间 | 叙述自己写了什么？是否只有神话人物，没有可落实的公历年代？ |
| 文本成书/编纂时间 | 是题署、古人归属说、现代研究判断，还是明确刊成记录？是否多阶段汇编？ |
| 当前现存见证/所读底本 | 本轮实际读的是抄本、刻本、影印本还是数字转录？注释与版本相隔多久？ |
| 当前研究或转录时间 | 哪些是现代断句、释义、图像、平台 metadata？是否误当原作信息？ |

正文、夹注、注文中的引文、辑佚重建与后世改写分别保留。字形、句读、释义的改变可能不同：

- 两电子文本“寒 / 塞”不同，未看两版本原页：记数字文本差异；可能涉及录入错误或版刻差异，不能先定一种。
- 同一段在不同网页相同：可能同源复制；检查底本与来源链，再决定是否独立见证。
- 注书引《博物志》一句：只证明已读注书如此引用；若依赖《博物志》的具体时代或完整语境，继续读原书或标转引。
- 后世诗赋把故事读成“报怨 / 猛志”：这是接受史材料；不能把该动机添加到更早的正文。

选择一个会影响白话、人物行为或视觉判断的争议深入。呈现支持与反证各自的文本位置；表明当前采用的读法是否暂定、别的读法会怎样改变判断。原字不清、缺叶、版本未知时停止断言，不用流行故事补空。

## 器物、服饰与空间

只围绕当前细节核查材质、形态、用途、断代、出土或征集信息、所据图像及馆藏号。有正式馆藏记录才填馆藏号；没有就写未核，不能从网页 URL 编号猜。

材料名称、实际成分、做旧效果及颜色可能不同。馆藏“青铜”不能自行细化铜锡比例；“玉”不能自动改成现代商品玉种；正面照片不能证明背面结构、尺寸或使用动作。断代范围照录并标机构，不能为了故事需要缩成某一年。

古物形制、晚期绘画、舞台服装、现代复原、AI 推测图分开。不用生成图证明真实古代穿着；不同朝代或地区的相似装饰，未见传播链时只作形态比较。

需要动画/表演线索时，先看物理可用动作与史料动作的证据，再给创作候选。比如“这只器物可握持”与“某祭礼确实这样使用”是两层判断。

## 传说与民俗

记录采录或文本形成年代、地区、记录者、讲述/仪式语境，以及实际所读范围。现代地方志中的传说，不能自动写成自远古连续流传；清代注释所引某庙的说法，也不等于已经考察现存庙宇。

“当前找到的最早记载”只限定本次检索，不能替代确切起源。记录年代早晚与传说声称的故事时间分开。没有年代/地域时按缺口保存；不得用共享名字替多个地区建立唯一正统版本。

## 跨题材关联

| 关联等级 | 可说什么 | 不能升级成什么 |
|---|---|---|
| 文献支持 | 实际原文把二者并写、明确转引或已有可定位的传播记录 | 不保证两故事本来同源、也不保证共同主题是唯一解释 |
| 研究解释 | 根据已核语境与形式提出相近关系，并说明推理条件 | 不等于来源自己宣称的联系或已证历史事实 |
| 仅相似 | 外形、语词、动作或感觉相似，作为创作联想 | 不等于影响、传承、古代交流或同一神祇 |

如果关系仍靠多重转述、年代相冲突或缺中间传播证据，不作强关系图。为了表达需要画示意时，边标等级、出处和未知；它只是当前研究图，不是历史定论。

## 一份够用的成果

根据范围选取：本轮问题与停止条件；实际原文和自译白话；版本或注释对照；与焦点直接相关的背景；图像/原页或清楚标注的文本定位示意；争议、反证、无法确认处；少量可带去创作的形式感觉候选；已读来源、定位、许可和工具实调记录。

正文使用小段 sourceRefs 支持具体说法，表格多类内容不要混在一个“来源事实”段落。来源未支持的推理拆出“研究解释”；未落实的创作选择拆出“候选”。技术解析退出码、检索数量和文章长短不证明研究质量。
