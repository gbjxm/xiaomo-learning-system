# 阶段1：机会内容层级与布局验收

2026-09-30完成。本轮只实施UI布局，未开展阶段2功能扩充，未重新采集或核验外部规则，未改变来源、时间、排序、资格或奖励的数据规则。

## 信息如何重排

| 位置 | 前置的信息 | 后置但仍可访问的信息 |
| --- | --- | --- |
| 首页 | 筛选与机会列表；本次检查的简短结果及失败/忙碌状态 | 更新摘要和资料概况收进可展开区域；侧栏管理入口保留 |
| 卡片 | 名称/轮次/准确图片、简介、奖励类别与数量及口径、资格、作品要求、截止和状态 | 字段记录度、人工交接与自动提取元信息退出卡片主信息 |
| 详情 | 简介与主办方、状态和截止、官方/报名行动链接、完整奖励与加入资格、作品要求、版权限制、投稿步骤、结算及时间 | 来源档案、标识出处、核验方法、采集覆盖、缺失字段、原文证据和历史默认收进尾部折叠区域 |

桌面详情奖励与资格并排；窄屏顺序阅读。卡片资格与作品要求显示已有原文前两项作为预览，详情保留全部内容；不是完整资格判定。图片与文字回退继续使用已有本地资产，未新增或改换官方图片。

现金、积分、算力等分别显示；总奖池与个人单奖/有条件上限的口径贴着金额。没有金额不补零、不编现金，未知资格不写成无限制。24:00原文、仅日期、月份精度、暂定截止、未知时区和状态冲突继续明确显示；已过期和未核机会仍按原有效性分组。重大首发、排他、著作权转让及持续履约限制在卡片提示，完整版权段落在详情直接可读，没有折叠到来源中。

来源折叠不是删除：点击“原文与证据”会先展开再定位，官方报名/活动入口一直在主要操作区。图片目录迟到时只补进来源区域，不把元信息重新放回正文前部。独立审查发现个人条件异步保存可能让新折叠标题保留旧判断，已改为固定说明，实际对照结果继续由原条件同步逻辑更新。

## 验收结果

- 前端自动回归100项通过：原排序/请求顺序/适配/图片81项，新层级与语义19项。完整结果见`output/layout-stage1/frontend-tests.json`。
- Python针对性检查31项通过：服务接口7项、本地图片安全24项。本轮没有改后端，未重跑全部Python测试。
- 真实库只读浏览器1054项检查通过，逐项打开46条，确认已整理的完整要求、奖励条件、版权、父子关系、附件和证据均保留。见`output/layout-stage1/browser-primary.json`。
- 隔离副本真实保存11项通过：重复关注与保存、失败不冒称成功、草稿保留、返回保留筛选、刷新与成功重试。见`output/layout-stage1/browser-save.json`。
- 额外浏览器11项通过：首页概况仍可展开、5条最长标题的证据跳转、390px触屏点开/关闭、真实坏图恢复文字。见`output/layout-stage1/browser-final.json`。桌面与390px截图已实际查看像素；减少动态效果、键盘、加载取消、最新请求优先、失败重试和返回位置由浏览器与前端回归共同覆盖。
- 隔离服务实际关闭、重启后，笔记仍与保存值一致，见`output/layout-stage1/restart.json`。

测试过程有两处工具/脚本问题：隔离全量脚本首次误匹配了隐藏作品表单的同名保存按钮，随后限定为详情按钮；浏览器工具会话一次断开，重建后以保存专测完成剩余流程。没有把这些未完成尝试算成通过。故障模拟期间出现连接重置日志，应用健康检查正常，隔离服务可正常关闭/重启。所有保存、失败和重启操作都在`output/layout-stage1/isolated.sqlite3`，没有在真实库写入测试笔记或收藏；没有执行真实采集。
