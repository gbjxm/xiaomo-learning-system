# 创作机会交互优化 · 2026-09-30

正式入口：[双击启动.cmd](../双击启动.cmd)，地址 `http://127.0.0.1:8765`。本轮修改 `static/app.js`、`static/index.html`、`static/style.css`，延续标准库与静态网页实现，没有新增运行依赖或后台采集。

## 设计选择与结果

1. 找机会时减少“看不见的条件”：搜索可一键清空，已选类型 / 平台 / 状态 / 奖励以可移除条件展示，也可全部清空。平台下拉取实际记录和已配置平台的并集。当前标签页记住筛选、排序、视图及列表位置；无结果提供恢复入口。
2. 把详情作为连续阅读空间：标题和正文都可打开详情；本机读取时立即显示可关闭的加载反馈。Esc、顶部返回或底部返回恢复原入口与列表位置，关联条目切换仍回到最初入口。关注只更新操作状态，保留详情滚动、焦点和草稿。段落导航新增“我的笔记”，完整条款与官方外链继续展开保留。
3. 保存与更新有准确反馈：关注和笔记按条目防重复提交；保存采用点击时文本快照，请求期间继续编辑不会被冒称已保存。草稿按记录保存在本标签页，关闭详情、关联切换、刷新可恢复；写入资料库仍需点保存。检查进度显示完成数量，通信失败标“状态未获确认”，重读状态不启动另一轮检查；采集失败、部分提取与待核不写成零更新。

未改变日期精度、时区、奖励口径、核验维度或有效优先排序。46条机会及原始证据全部保留，未补充新平台内容。

## 现有边界

筛选和未保存草稿属于同一标签页的sessionStorage，关闭标签页可能清除；保存后的笔记属于SQLite，跨启动保留。清除筛选不会清除笔记。浏览器禁用存储时会提示先保存。

采集能力沿用既有覆盖：仅LibTV公开活动列表具备自动发现适配，其他来源是已知URL核对、主页或尚未适配。登录、验证码、robots及图片规则限制仍保持原有标记；本轮没有新增登录、付费OCR或宣称这些来源已接通。

本轮无未解决的实施阻碍。正式服务已启动且只监听localhost；验收浏览器与QA服务关闭后，双击原入口即可继续使用。
