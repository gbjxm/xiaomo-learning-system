## 默认排序和时间精度

1. 人工官方证据支持的已核精确时间窗口、明确常年开放机制、已生效规则。
2. 官方公告日期或月份范围内，但开放仍待确认。
3. 已核官方证据支持的尚未开始/生效。
4. 开放或规则待核，包括冲突、暂定、未知、仅自动提取或核验较久。
5. AI限制、推广合作、版权不建议或付费尽调参考。
6. 已截止与历史参考，保留在首页末尾，也能在历史归档查询。

所有排序选项保持上述分组。默认组内按保守UTC截止范围、最近人工核验/公告日期排序，以记录ID收尾，确保同时间顺序稳定；金额不参与。个人资格、AI资格、本机最新抓取失败分别显示，不将账号未核或一次抓取失败等同于已核公开机制失效。

新增`window`状态，明示日期/月精度与未知时区范围内仍为“开放待核”。冲突、暂定、缺截止不标确认开放；月初/月末和政策生效/终止的未知时区边界保守判断。月份边界仅在内存比较，不保存编造日时；24时原文继续保留，奖项有效期/政策期/报名期不混用。
