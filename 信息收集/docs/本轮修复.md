# 公开来源提取与覆盖维度修复

本轮修复了星图帮助页正文范围、花火通知公开JSON、LibTV规则段落提取，并将公开正文、规则字段、本账号资格分开记录和展示。完整规则检查仍保持原标准，不将账号未连接解释为正文失败，也不将取得文字解释为图片或完整条款已核。

## 0完整的准确原因

原文章分支无论取得多少文字都固定返回“partial”；星图正文已经在HTML里，但旧解析器把导航与正文混在一起，没有识别官方文章容器。花火通知的富文本藏在 `window.__initialState` 的公开JSON中，旧解析器跳过脚本，结果只保存标题。LibTV虽解出了12条嵌入正文，但固定段落标题漏掉“如何参赛”等写法，行内加粗又会错误截断投稿步骤。

这些技术问题已修复。另一部分仍是真实缺口：文章只是计划定位/升级说明，没有完整加入与收益条款；规则含图片或外链；B站opus返回验证码。个人账号没有连接是第三个独立维度，并非上述正文失败的理由。

## 剩余需要决定的范围

- 图片规则：需要人工识读或OCR；本轮没有使用付费OCR。可以以后选择人工整理或本地免费工具，不应以此推断图片无更新。
- 个人账号：分批开放、实际加入资格与收益需要账号证据或另行授权登录；本轮没有请求或使用登录态。
- 验证页面：3条opus已停止自动读取，可由用户自行查阅并提供官方正文。没有尝试替换端点或绕过验证。
- 临时网络：updream本轮TLS握手超时，保留失败并退出；后续可按需重试，不将此误报为必须登录或付费。
- 其他公开规则及外链：仍可在公开可读范围继续适配，当前缺口已保留，不把这些都称为需要登录。未新增平台或大功能。

现有[双击启动.cmd](../双击启动.cmd)、[更新一次.cmd](../更新一次.cmd)保持可用。平时浏览只读本地资料，`python app.py update`仍是单次更新，没有后台定时。修复后完整导出：[library-export.json](../output/repair/library-export.json)。
