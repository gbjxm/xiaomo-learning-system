阶段1布局调整已完成：卡片与详情先读简介、奖励、门槛、时间及参与限制；来源与采集历史后置折叠，报名链接保留在前部。首页概况可展开，数据规则与资料未改变。实际截图、测试和保全见[阶段1内容层级与布局验收](docs/阶段1内容层级与布局验收.md)。阶段2已完成候选审核、证据复核、有限分页、正文搜索与保存视图、多作品准备、保守归并及便携备份，使用方法、验收证据和限制见[阶段2信息库闭环验收](docs/阶段2信息库闭环验收.md)。

当前标识覆盖已按用户偏好补齐：31条赛事全部有图（19活动图、12平台／主办方／公司标识）；全部46条机会42有图、4文字回退。即梦、LibTV等已补，来源与限制见[平台标识补齐验收](docs/平台标识补齐验收.md)。

双击 [双击启动.cmd](双击启动.cmd)，浏览器会打开 `http://127.0.0.1:8765`。需要本机已安装的 Python 3.12，无需安装第三方运行依赖。

启动和刷新页面只读取已保存资料，不采集。点击网页右上角「检查更新」检查一轮；重复点击复用当前任务。结束后在「官方信源」查看每个来源的实际结果与时间。

点击「停止服务」、关闭启动窗口或按 Ctrl+C 退出。下次双击启动，资料、关注和笔记仍在。检查中的网络请求有超时，停止时可能需要等待当前请求退出。没有定时采集、开机补查、后台自启或云部署。

未保存的笔记草稿留在当前浏览器标签页，关闭详情、切换关联条目、刷新或本地服务重启后仍可恢复；关闭标签页可能丢失草稿。点击「保存笔记」才写入本机资料库，已保存笔记可导出且跨启动保留。浏览器禁止标签页存储时会明确提示先保存。

也可在本目录运行：

```powershell
python app.py serve --open
python app.py update
```

`更新一次.cmd` 是单次检查的双击入口。`update` 结束即退出，不常驻；退出码 `0` 表示本轮没有网络/解析失败（仍可能有部分提取和未接通），`2` 表示有信源失败，`3` 表示已有检查运行，`1` 表示程序未完成。逐源报告才是覆盖结果依据，退出码0不等于所有来源完整核验。

只检查指定来源：

```powershell
python app.py update --source libtv
```

## 看懂资料

- 「新发布」只依据已核公告发布时间，不以发现时间代替；与已核开放、公告窗口内（开放待核）、尚未开始独立判断。
- 时间机制包括明确起止、官方明确常年开放、分批分期、官方未说明。长期机制即使没有截止也继续展示；缺截止不会被视为永久有效。
- 报名时间、政策生效时间、奖励有效期分别保存。官方未注明时区时保留未知，接近边界显示待核验。
- 有已核截止的历史记录归档而不删除。活动周期已经过去而报名正文不全时，显示「可能已结束 · 截止待核」，不自动归档。
- 现金总奖池、单奖、积分、算力、流量、推广和展映分别标注，不能相加冒充现金收益。花火为商业撮合机制，精选计划的内容扶持也不等于已核现金分成。
- 默认按已核有效、公告窗口内、尚未开始、待核、限制参考、历史分组；同组按临近截止与近期核验稳定排列。切换近期发布或相关度也保留这些分组。相关度来自 `config/rules.json`，不代表账号或作品一定符合资格。
- 每条详情保存资格、作品要求、步骤、版权/首发限制、缺失字段与证据；长期机制另外保存加入、收益、结算、持续达标、退出和生效版本。

人工移交种子与本机抓取证据分开。2026-09-30移交的长期机制保留核验日期；早期种子未提供精确核验时刻的字段保持空。王者计划另有本次人工补充版本。四类长期机制的专属 AI 内容资格均未核到，不能默认 AI 作品符合。

## 更新摘要与作品条件

首页「本次更新」区分新增条目、发现线索、延期、奖励／规则变化、到期和失败；「更新批次」可回看最近20批的前后差异、记录时间和官方原文。页面导航或排版变化只进入待复核，不直接说成规则修订。旧批次缺少前后快照时明确标注重建限制，全部旧历史仍保存在数据库及完整备份中。

打开「我的作品条件」，填写时长、学生身份、工具、是否已发布、AI使用和占比，点击保存后才参与对照；全部字段默认待确认，不替用户确认历史背景。只有带适用届次官方证据的结构化条件参与符合／不符合／待确认判断；资格审核、会员、账号及具体赛道条件仍需另核。当前9条有结构化对照规则，其他未知条件不会被误排除。条件只在本机保存，随完整备份恢复。

## 维护、备份与补充核验

- `data/opportunities.sqlite3`：实际数据库，包含版本、抓取证据、差异、运行记录、关注、笔记及作品条件。
- 「备份与恢复」：创建含9张表及来源／筛选配置的完整ZIP，保存在`data/backups/`，可下载另存。恢复须预览影响后点击明确确认，恢复前自动留快照；预览后资料改变或检查仍在进行时拒绝恢复。取消不改资料；不自动恢复。回复中断时可重读本次操作收据，不自动再次恢复；资料重读前暂停保存。持久日志在中途退出后核对数据库与配置；外部陌生配置修改会保留快照并停止覆盖。外部保存的本应用ZIP可复制回`data/backups/`再刷新列表，保留原文件名。损坏、不兼容或危险备份会被拒绝。
- 完整ZIP包含数据库内的原文文字、证据字段与全部历史，不包含`output/`中的研究附件二进制、截图及测试副本；如需保留这些文件，请另复制项目。资料导出JSON用于查看／增量补核，不是完整恢复备份。
- `config/sources.json`：官方源与允许访问的域名，修改后重启服务。外部网页不会自行扩展允许域名，也不会执行网页里的脚本或指令。
- `config/rules.json`：筛选与相关度参数，修改后重启。
- `opportunities/seeds.py`：有出处的首次初始化种子，不是示例数据；只在新数据库中初始化一次。
- `config/reviewed_supplement.json`：本次人工补充王者规则的可审阅记录。

点击侧边栏「导出我的资料」，或执行：

```powershell
python app.py export output/my-library.json
```

导出包含条目、所有版本全文快照、正文证据与差异及本地关注笔记。若要补充已核信息，可从导出文件复制一条 `documents` 记录，核对官方证据后填写缺失字段、核验时间，并保存为本项目内的 JSON：

```powershell
python app.py import config/my-reviewed.json
```

同一来源、官方 URL、年度轮次更新会形成版本；不同年度和轮次分别保留。明确填写 `edition`，不要把新一轮直接覆盖成旧轮次。导入主要用于人工核验字段的补充；恢复整个信息库请使用数据库备份，导入条目不重建全部旧历史或关注笔记。

平台页面的文本变化保存为「待复核」差异，不直接替换人工已核规则。抓取到的原文通过纯文本展示；核对后可通过 JSON 补充形成新的人工版本。
